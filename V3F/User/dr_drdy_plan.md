# 地磁 DRDY 中断架构方案

## 1. 现状与耗时

当前每帧（685.8 Hz，周期 1.458 ms）在主循环里做：

| 步骤 | 耗时 | 是否阻塞 |
|---|---|---|
| 写 CTRL0 = TM_M\|INT_MEAS_EN 触发 | ~10 µs | — |
| **轮询等 Meas_M_Done** | **~500 µs** | ★ 长阻塞 |
| 连读 7 字节 | ~20 µs | — |
| 写 STATUS 清锁存 | ~10 µs | — |
| **printf（921600 波特）** | **~300 µs** | ★ 长阻塞 |
| **合计** | **~840 µs ~ 1 ms** | |

**占用近 1.46 ms 周期的 60%** —— 这就是"地磁中断会很慢"的答案：**是，必须移交小核、且必须允许陀螺抢断。**

## 2. 小核 V3F 中断分工（现状）

| IRQn | 编号 | 服务对象 | 当前优先级 |
|---|---|---|---|
| `EXTI7_0_IRQn` | 36 | **地磁 DRDY（PE1 = EXTI_Line1）** | 0 |
| `EXTI15_8_IRQn` | 33 | 陀螺 INT1（PD11 = 线11）+ 复位键（PB10 = 线10） | 1 |

## 3. 目标架构

```
                    ┌─────────────────────────────────────┐
陀螺 DRDY (7680Hz)  │ EXTI15_8_IRQHandler   抢占级 0（最高）│  ← 必须能抢断地磁
  周期 130 µs       │  · 判线 11 -> 陀螺处理体（短）        │
                    └─────────────────────────────────────┘

                    ┌─────────────────────────────────────┐
地磁 DRDY (≈1000Hz) │ EXTI7_0_IRQHandler    抢占级 1        │  ← 允许长阻塞
  周期 1000 µs      │  · 读 X/Y/Z 7 字节                    │
                    │  · 写 STATUS 清锁存                    │
                    │  ★ 判断下周期 SET/RESET 并处理          │
                    └─────────────────────────────────────┘
```

### 为什么陀螺必须更高

- 陀螺周期 **130 µs**，地磁 ISR 阻塞 **~540 µs**
- 若地磁优先级更高，陀螺会被堵住 **4 个周期**，直接丢帧
- 地磁周期 1000 µs，被陀螺抢断几十 µs **不影响**它自己的节拍

**结论：陀螺抢占级 0、地磁 1、复位键 2。**

## 4. SET/RESET 极性处理（中断内）

### 极性切换的机制

```
set 周期：CTRL0 = TM_M | INT_MEAS_EN | AUTO_SR_EN              （自动 SET）
rst 周期：CTRL0 = TM_M | INT_MEAS_EN                           （不自动 SET）
                   ↓ 且在触发前发 RESET 脉冲
          CTRL0 = Reset(0x10)  单独一拍，等操作结束（≥100 µs）
```

### 中断内流程

```
ISR(地磁 DRDY):
  1) g_mmc_drdy_ts = GetTime64_10Ns()
  2) 读 X/Y/Z 7 字节                      （~20 µs）
  3) 写 STATUS = 0x03 清锁存               （~10 µs）
  4) 交替极性：
       若本拍极性 == SET -> 下一拍用 RESET
       否则             -> 下一拍用 SET
  5) 若下一拍是 RESET：
       写 CTRL0 = Reset(0x10)              （~10 µs）
       HWT_DelayUs(100)                    （RESET 操作 ~500ns + 余量）
     若下一拍是 SET：
       写 CTRL0 = INT_MEAS_EN | AUTO_SR_EN
  6) 写 CTRL0 = TM_M | INT_MEAS_EN          触发下一拍
  7) 退出（可被陀螺抢断）
```

**阻塞上限 ~ 640 µs，小于 1000 µs 周期，可行。**

### 零偏计算（跨周期配对，沿用归档机制）

```
offset = (RESET 样本 + 下一个 SET 样本) / 2
         ↑ 两者时间上最接近（~623 µs），外界磁场相消最好
```

## 5. 数据落地

中断里只做"读原始值 + 存到缓冲区 + 翻转极性"，**不做浮点**（RISC-V ISR 碰 FP 寄存器要额外保存/恢复，会把 80ns 的进出变成数百 ns）。

- 原始 counts 存 `int32_t g_mmc_raw[3]`
- 极性标记存 `uint8_t g_mmc_polarity`（0=SET, 1=RESET）
- 时间戳存 `uint64_t g_mmc_drdy_ts`（`GetTime64_10Ns()`）
- 消费端（主循环或共享区）再做零偏配对与换算

## 6. 待确认项

1. **地磁是否保留"连续自动测量"**，还是完全改为"中断里手动触发下一拍"？
   - 前者：中断只读数据 + 翻极性（但极性切换需要临时改 CTRL2，与自动测量冲突）
   - 后者：中断里显式触发每一拍（本方案采用，控制最干净）

2. **陀螺 DRDY 中断现在是否要一并实现**？目前 `EXTI15_8_IRQHandler` 里陀螺分支只做计数+打印。

3. **printf 是否移出中断**？建议中断内不打印，改由主循环低频上报。
