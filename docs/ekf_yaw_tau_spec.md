# 地磁偏航牵引速度（τ）规范 —— 无歧义数学定义与实现机制

> **状态（已更新）**：本规范的"固定 τ"方案已被 `docs/ekf_yaw_timescale.md` 取代 ——
> PC 仿真（§6 there）证明把 τ 钉在 1.5 s 会把陀螺的短期优势扔掉（1 s 增量误差 0.312° vs
> 物理底 0.0090°）。**最终落实的是 M3：把地磁偏置建成状态（VER=132），不使用 τ。**
> 本文件保留"τ 只能这样定义、这样声明"的规范价值（第 1~2 节与第 5 节审计）。

> 目的：把"静止态地磁偏航牵引 τ = 1.5 s"这件事，写成**唯一确定、可验证、与 P/R 实现细节无关**的数学陈述。

## 1 符号与定义

| 符号 | 含义 | 固件对应 |
|---|---|---|
| `dt` | 地磁观测间隔（次数率 f = 1/dt） | `V5F_MAG_EPOCH_DT_S = 5.26 ms`（IST ~190 Hz） |
| `ν_k` | 第 k 次偏航观测的新息（innovation），导航系偏航角 | `wrap(thm − thp)` |
| `P⁻_k` | 该次更新**之前**的偏航方差（a priori） | `s_P[8][8]` |
| `R_k` | 本次更新**使用**的偏航量测方差 | `ekf_mag_entry_plane/vec` 的 `R1[0]` / `RRv[0]` |
| `K_k` | 本次更新的偏航增益 = `P⁻/(P⁻ + R)` | 偏航行 |
| `e_k` | 偏航估计误差（真值 − 估计） | — |

**时间常数的唯一定义（离散、精确）**：闭环误差按
`e⁺ = (1 − K)·e⁻ + w`（w 为两次观测间注入的噪声/漂移）演化，定义

```
λ  ≜ 1 − K                       （每次更新的衰减因子）
τ  ≜ −dt / ln(λ)                 （精确的 e-折时间；K ∈ (0,1) 时恒有定义）
⇒  K* = 1 − exp(−dt/τ*)          （反解：给定 τ* 得到唯一确定的增益）
```

数值：`dt = 5.26 ms`、`τ* = 1.5 s ⇒ K* = 1 − exp(−3.5067e-3) = 3.5006e-3`
（注意：常见近似 `K ≈ dt/τ` 给 3.5067e-3，**差 0.17%**；规范里一律用指数式，避免二阶歧义。）

**稳态滞后（另一个可验证量，用来交叉检查）**：若偏航有恒定漂移率 `b`（rad/s），
则稳态误差 `e_∞ = b·dt/K*`（小 K 时 ≈ `b·τ*`）。

## 2 目标行为（规范陈述）

> **当一次偏航观测被接受时，其偏航增益恒等于 K\*：`K_k ≡ K*`。**
> 等价地：闭环偏航误差的每次衰减因子恒为 `1 − K*`，e-折时间为 `τ*`，
> 与 `P⁻_k`、`R_nom`、倾角不确定度、失效门历史**全部无关**。

这是唯一的验收口径：**"τ = 1.5 s" ⟺ "每次被接受的偏航更新，K = 1 − exp(−dt/1.5)"**。
（不允许出现"τ ≥ …"、"τ ≤ …"、"地板/上限"这类只在部分区间成立的表述。）

---

## 3 实现机制：**按 K\* 反解 R**（R 调度 / deweighting，KF 标准手法）

单个标量观测下 `K = P⁻/(P⁻ + R)` 是双射，故**把 K 钉住 ⟺ 把 R 按状态取值**：

```
R_k  ≜  P⁻_k · (1 − K*) / K*                 （无条件赋值，不是 max/min）
⇒  K_k = P⁻/(P⁻ + R_k) = K*/(K* + 1 − K*) ≡ K*      （恒等式，对任意 P⁻ > 0 成立）
```

- **精确性**：这是代数恒等式，不依赖 P⁻ 的大小、不依赖 Q、不依赖倾角项。
- **协方差更新**照常做（Joseph 形式），用的就是 `R_k`；**不对 P 做任何钳位**。
  即"不动 P、不动 K，只动 R"，语义单一：*本次观测被声明为多噪*。
- `R_k` 与传感器真噪声 `R_nom = σ_h² + (tanI·σ_tilt)²` 的关系：
  - `P⁻ > R_nom·K*/(1−K*)` ⇒ `R_k > R_nom`：**降权**（声明地磁更吵），这是允许的自由度；
  - `P⁻ <` 该值 ⇒ `R_k < R_nom`：**过信**地磁（比标称噪声更相信它）——策略选择，见 §6。

**分段（唯一的分段判据）**：`|w| < W_S`（`V5F_MAG_DIST_WMAX_DPS = 5 dps`，与一致性门同源）
时的观测走"静态支路"，取 `τ* = τ_static`；否则走"运动支路"，**保持现状**（自然增益，
`Q_YAW_MAX` 限制），本规范不动运动支路。切换点附近用连续 `N_sw` 帧去抖（例如 `|w|` 连续
5 帧满足才切换），并在实现里注明：增益在边界处**不连续**（静态支路的 K\* 与自然增益不同），
去抖只影响切换时刻，不影响 `K ≡ K*` 这一恒等式。

## 4 由 K\* 决定的两个**派生量**（必须一起改，否则又是歧义）

1. **NIS / 卡方检验**：`S = P⁻ + R_k = P⁻/K*`，故 `NIS = ν²·K*/P⁻`。
   在真实工作点（`P⁻ ≈ 2e-3`、`K* = 3.5006e-3`）下 `K*/P⁻ ≈ 1.70`，阈值 `16.27`
   ⇒ `|ν| < √(16.27·0.588) = 3.09 rad = 177°` 都收
   ⇒ **偏航的卡方拒收实际上失效**。这不是 bug 而是"固定带宽"的必然代价，必须显式声明。
   （同时 `R_k = P⁻(1−K*)/K* ≈ 0.586 rad²`，σ = **44°**：等于向滤波器声明"地磁偏航有 44° 噪声"，
   这就是把 τ 钉成 1.5 s 的代数代价。）
   ⇒ 若仍要野值防护，**改用对新息本身的固定门限**：`|ν| > ν_max` 时拒收该次观测
   （建议 `ν_max = 20°`，与 `V5F_EKF_MAG_R_MAX_DEG` 同量级），于是
   "接受/拒收"与"接受时的增益"两件事解耦，二者都无歧义。
2. **失效门（一致性门）**：仍是"是否接受观测"的判据，与 K 无关；保持 `VER=127` 参数不变。

## 5 与旧实现的差别（歧义审计）

| 版本 | 代码做了什么 | 正确的数学陈述 | 问题 |
|---|---|---|---|
| VER=125 | `R := max(R_nom, P⁻(1/K_max − 1))` | **K ≤ K_max**（增益上界） | 只在 `R_nom` 更小时生效；实际静止 `R_nom >` 门限 ⇒ **从未生效**，所谓 "τ ≥ 15.85 s" 不成立 |
| VER=130 | `P := max(P, R_nom·K*/(1−K*))` | **K ≥ K\***（增益下界） | 实际静止 `P⁻ = 2e-3 ≫` 门限 `2.1e-5` ⇒ 地板不吃力，实际 `K = 0.26`、`τ ≈ 20 ms`；"τ = 1.5 s" 是**错的标签** |
| VER=131（本规范） | `R := P⁻(1 − K*)/K*`（等号） | **K ≡ K\***（把 τ 钉死） | 无区间、无条件，可逐帧验证 |

⇒ 教训写进规范：**任何用 `max()/min()` 包起来的 P 或 R 赋值，都只能声明成不等式；只有等号赋值才能声明 τ。**

## 6 待确认的策略选择（实现前需要拍板）

1. **是否允许 `R_k < R_nom`（过信地磁）**：
   - (a) 允许（推荐）：`K ≡ K*` 无条件成立，静止 τ 精确 1.5 s；代价是静止时地磁自身标定误差按 1.5 s 时间常数进入姿态。
   - (b) 不允许：加 `R_k := max(R_nom, P⁻(1−K*)/K*)`，但**必须同时把规范改成**"`K ≤ K*`，且在 `P⁻` 足够大时 `K < K*`" —— 即**放弃"τ = 1.5 s"这个说法**。二选一，不能含糊。
2. **τ_static 的数值**：1.5 s（= K\* 3.5006e-3）？还是别的（如 1.0 / 2.0 s）？
3. **`ν_max`（固定新息门限）**：设 20°？还是继续用卡方并接受"偏航几乎不拒收"？

## 7 验证协议（可逐帧判定，不靠"看起来对"）

1. **遥测直接验证（最硬）**：把本次更新**实际使用**的 `R_k`（或 `K_k`）发布到调试帧
   （`ekf.mag_ry` 已有类似语义，或占用一个空列；验收帧可加第 6 路 float）。
   判据：静态段 `K_k` 逐帧等于 `1 − exp(−dt/1.5)`，误差 < 1e-6。
2. **间接验证（不依赖新列）**：由发布量反算 `K_meas = p_yy/(p_yy + R_applied)`；
   若 `R_applied` 不发布，可用恒等式 `R_applied = P⁻(1−K*)/K*` 检查一致性（自洽而非独立）。
3. **行为验证（闭环）**：静止段人为/自然出现偏航阶跃（例如手动转台面后松手），
   从调试帧取 `ν_k` 序列，离线递推 `e_{k+1} = (1−K*)e_k`，与 `e_k ∝ ν_k` 的实测衰减比较，
   拟合 e-折时间应在 1.5 s ±10%。
4. **回归项**：`p_yy`（col121）不再被地板抬起；`sigma_yaw`(104) 恢复为滤波器自身值
   （静止时应随时间线性增长，∝ σ_b·t）；运动支路行为不变（与 VER=130 逐帧一致）。
