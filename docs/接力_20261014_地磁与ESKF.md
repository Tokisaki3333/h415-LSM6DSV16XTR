### 1.4 建立的分析口径（用户指定，唯一合法）

```
真磁残差(t) = angle( z_meas(t) , R(q_nomag(t))ᵀ · v_mag )

  z_meas = (mag − MAG_ZERO)/|·|   或 magmap 正路 cal[want] 球心（两者自洽）
  q_nomag = 【未融合地磁的 EKF】姿态（pc_chain_nomag 输出）
  v_mag   = 世界系场参考；由运动前静止段拟合，或取板上 EKF 实际值（两者自洽）

★ 禁止: 用"融合了地磁的 EKF"与"未融合的"作比较（磁开结果在参数未定时无物理意义）
★ 分段 = 每两个磁数据之间为一段（段极短 ⟹ 无 180° 环绕）
★ 物理含义: q_nomag 可信 ⟹ 残差 = 地磁链 + 姿态误差在 ⊥场 方向的投影
```

## 2. 残留任务（按优先级）

### 2.1 ★★★ 实施率相关 `k_s`（最高优先，已定位到行）

**问题**：`proc_eskf.c:1108`
```c
qg += 2.0f * ESKF_KS_SCALE * ESKF_KS_SCALE * s_throt_acc * wn * dt_s;
```
用单一 `k_s = 75 ppm`，而实测率相关（130 ppm @<600dps，220 ppm @1700dps）。

**后果**：Q 在高速段偏小 `(220/75)² = 8.6` 倍 ⟹ P 偏小 ⟹ **所有观测的 `K = P/(P+R)` 偏小** ⟹ 磁牵引弱、重力重锚慢。
（地磁通道已无 IGG ⟹ 牵引强度**完全**由 K 决定 ⟹ 这是唯一解释。）

**建议实施**（`k_s(|ω|) = k0 + k1·|ω|`，`|ω|` 单位 dps）：
```c
/* 实测两点拟合: |ω|=400 → 130 ppm, |ω|=1600 → 220 ppm */
#define ESKF_KS_K0   1.0e-4f     /* 100 ppm */
#define ESKF_KS_K1   7.5e-8f     /* 0.075 ppm per dps */
...
float ks = ESKF_KS_K0 + ESKF_KS_K1 * wn;
qg += 2.0f * ks * ks * s_throt_acc * wn * dt_s;
```
**验收判据**：四份转动录制（**A `025232` / B `034941` / C `033516` / D `043549`**，见 §4.3.1）PC 复刻重跑：
- `mag_resid` 中位与末段应【下降】（现为 0.31~1.15°）
- 高速段（\>1200 dps）的 `mag_resid` 应显著改善
- 重力门行为不得变差（`grav_open` 开率、`acc_resid`）

**替代方案（更简、更保守）**：直接把 `ESKF_KS_SCALE` 提到 **200 ppm**（高速端对，低速端偏大 1.5 倍）。

```
★ 若 a 的启动方向有误差 ⟹ v_mag 倾角永久偏 ⟹ 重力与磁在倾斜上分歧
★ 用户已确认"放回台座姿态正确"⟹ 重力无误差 ⟹ 该路径未必有问题
★ 但: 用户建议的方案1（在线精化标量夹角 θ_est）尚未实现，也未验证是否有收益
   建议形态（防自陷）: θ_est ← θ_est + k·(angle(a,m) − θ_est)，k 小（时间常数数十秒）
                        v_mag = [0, cos(θ_est), sin(θ_est)]  ← 由标量重建，不做姿态回代
```

### 3.7 重力门与 `k_s` 的关系（本会话曾推理错误，已纠正）

```
★ 错误链条（曾提出后被用户否证）:
   "k_s 偏小 ⟹ P 偏小 ⟹ 重力门自锁"
★ 否证: 现用 75 ppm 跑，而高速录制实测 200+ ppm，重力门【没有】自锁
★ 正确理解:
   · 自锁需要【两个条件同时满足】: ① P 偏小（S 塌到 R）② 残差 r 远大于 R
   · 重力门开门条件是 | |a|−1 |<0.05 且 |ω|<20 dps ⟹ 门一开残差本来就小
     ⟹ 即便 P 偏小，rd 也不会越界 ⟹ 不自锁
   · ★ 所以"高速录制没自锁"是【残差小】决定的，不能用来检验 k_s
★ 另: ESKF 的 IGG 有 WMIN=1e-3 【地板】（不是拒绝）
   ⟹ 不是数学意义上的锁，但收敛时间常数被拉长 1000 倍 ⟹ 录制时长内表现为锁
```
