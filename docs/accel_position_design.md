# 加速度-位置测量系统设计

> 前置：陀螺处理链（零偏校正 / 动静判定 / 四元数）已定稿，见 `V5F/User/inc/v5f_proc.h`。
> 本文设计在其之上扩展的**加速度校正 + 去重力 + 速度/位置积分 + 零速修正**。
> 所有量级都取自本机实测，不引用器件手册。

## 0. 定位与边界

先把"能做什么"钉死，避免设计目标跑偏：

| 场景 | 纯惯导位置误差 | 结论 |
|---|---|---|
| 10 s | ~0.1 m | 可用 |
| 30 s | ~2 m | 勉强 |
| 60 s | ~12 m | 不可用 |
| 5 min | **0.7 ~ 1.3 km** | 完全不可用 |

二次积分把任何 0.1 mG 级的东西放大成公里。所以本系统的定位是：

**短时（秒级到十几秒）高带宽的相对位移测量 + 静止时用零速修正把误差归零。**

目标指标（建议）：

| 指标 | 目标 | 依据 |
|---|---|---|
| 输出速率 | 内部 8 kHz，上报可配 | 沿用现有链 |
| 加速度噪声底 | 待实测（见 §8） | 决定 1 s 内的分辨率 |
| 10 s 相对位移误差 | < 0.15 m | 陀螺倾角项主导（§6） |
| 静止零偏牵引后 a_lin 残余 | < 1 mG | 比不牵引改善 10~20 倍 |
| ZUPT 后速度 | 严格 0 | 位置误差不跨静止段累积 |

## 1. 信号流

```
accel_lsb[3] ──标度/交叉/零偏──> a_b [m/s²]（机体系比力）
                                     │
                     q（机体->导航）──┼──> f_n = R(q)·a_b
                                     │
                    g_n = [0,0,-g] ──┴──> a_lin = f_n + g_n      去重力后的线加速度
                                              │
                              积分 ───────────┴──> v_n ──积分──> p_n
                                              │
                    静止门（处理函数 2）───────┴──> ZUPT: v_n ← 0
                                                    零偏牵引: b̂_a 收敛
```

## 2. 处理链扩展

沿用现有"一函数一文件、结果写回 `g_v5f_hold`、返回 0 = 正常"的契约：

| 序 | 函数 | 文件 | 输入 | 输出 |
|---|---|---|---|---|
| 1 | `v5f_proc_gyro_bias` | `proc_gyro_bias.c` | `gyro_lsb`,`gate` | `imu.gyro_dps`,`imu.gyro_bias_dps` |
| 2 | `v5f_proc_static_detect` | `proc_static_detect.c` | `imu.gyro_dps` | `stat.*`,`gate` |
| 3 | `v5f_proc_attitude` | `proc_attitude.c` | `imu.gyro_dps` | `att.q` |
| **4** | **`v5f_proc_accel`** | **`proc_accel.c`** | `accel_lsb`,`att.q` | `vel.accel_mps2`,`vel.accel_bias` |
| **5** | **`v5f_proc_vel`** | **`proc_vel.c`** | `vel.accel_mps2`,`att.q`,`gate` | `vel.vel_n`,`vel.pos_n` |

主任务区顺序：

```c
st = v5f_proc_gyro_bias(&g_v5f_hold, &g_v5f_proc_gate);
st = v5f_proc_static_detect(&g_v5f_hold, &g_v5f_proc_gate);
st = v5f_proc_attitude(&g_v5f_hold);
st = v5f_proc_accel(&g_v5f_hold);                     /* 校正 + 去重力 */
st = v5f_proc_vel(&g_v5f_hold, &g_v5f_proc_gate);     /* 积分 + ZUPT + 零偏牵引 */
```

**5 必须在 4 之后**：它要回写加速度计零偏，作用于下一帧 —— 与陀螺那边"本帧结果写门控、下一帧读"同样的**后验、依赖前项结果**结构，不要改成同帧闭环（会引入代数环）。

## 3. 数据结构

`SPI_rx.h` 新增，挂进 `v5f_hold_t`：

```c
typedef struct {
    float            accel_mps2[3];   /* 标度/交叉/零偏校正后的比力（机体系）m/s² */
    float            accel_bias[3];   /* 当前零偏估计（机体系）m/s²，便于观察 */
    float            lin_accel_n[3];  /* 去重力后的线加速度（导航系）m/s² */
    volatile uint8_t corr_valid;      /* 1 = 本帧结果有效 */
    volatile uint8_t bias_ok;         /* 1 = 零偏牵引已收敛（累计静止 ≥ 3τ_boot） */
    uint8_t          flags;           /* 位标志 */
    uint8_t          _rsv;
} v5f_accel_t;

typedef struct {
    float            vel_n[3];        /* 导航系速度 m/s */
    float            pos_n[3];        /* 导航系位置 m（相对本段起点） */
    volatile uint8_t valid;
    volatile uint8_t zupt;            /* 1 = 本帧执行了零速修正 */
    uint8_t          _rsv[2];
} v5f_vel_t;
```

## 4. 量纲与常量

| 量 | 值 | 说明 |
|---|---|---|
| 加速度标称标度 | 2048 LSB/g（±16 g 档，`spi_hw.c` ACCEL_CONFIG0=0x03） | 1 LSB = 488.28 µg = **4.7889e-3 m/s²** |
| g | 9.80665 m/s² | 去重力用固定值；精确定位需按纬度算 |
| 陀螺标度 | 16.2753 / 16.4366 / 16.4235 LSB/dps | 见 `v5f_proc.h` |

加速度侧与陀螺用**同一个模型形式**：

```
a_true = K_a · (accel_lsb − b_a) / S_a
```

`S_a` 逐轴、`K_a` 对称（对角 1）。反对称项（安装失准）对静态六面标定不可观测，同理不进模型。

## 5. 标定

**建议与陀螺的六面零偏校正一次做完** —— 同一批静止姿态，两套参数一起解：

| 参数 | 方法 | 说明 |
|---|---|---|
| `S_a[3]` | 六面 ±g 投影；或翻转夹具（与陀螺整圈同思路） | 每面 f 应等于 ±g 沿该轴，6 面给 6 个方程解 3 零偏 + 3 标度 |
| `K_a` 对称非对角 | 再加 3 个倾斜姿态（非正交朝向）联立 | 与 `joint_fit2.py` 同一套最小二乘 |
| `b_a[3]` | 六面给初值；**在线静止牵引**持续修正 | 见 §6 |
| 杆臂 r | 若 IMU 不在旋转/振动中心 | 需补 `ω×(ω×r)` 与 `r×α` 两项，否则机动时误差可达几十 mG |

六面/倾斜姿态的方程组是线性的（`f_meas = K_a·R^T·g_vec/…`），可以直接用现成脚本改；
**注意别再犯耦合标定时那个错**：记录时固件的传递阵版本不同要分开处理。

## 6. 零速修正与零偏牵引（核心）

门控直接复用处理函数 2 的 `gate->is_static`，不新增判据。

### 6.1 加速度计零偏牵引

静止时：

```
b̂_a += (f_n − ĝ_n) · dt / τ_a          f_n = R(q)·a_b,  ĝ_n = R(q)·[0,0,-g]
```

**为什么这样能同时消掉零偏和倾角误差**：静止时水平残差 = `b_a − g·ε`（两者不可分），
牵引把它拉到 0 就得到 `b̂_a = b_a − g·ε`；运动开始后代回去，两项符号相反、互相抵消。

参数与陀螺对齐：

| 参数 | 值 | 说明 |
|---|---|---|
| `τ_a_boot` | 2 s | 启动段，累计静止 3τ 后切工作段 |
| `τ_a_work` | 12 s | 工作段 |
| 回退 | 24 格 × 20 ms = 480 ms | 静止→运动边沿，沿用 `V5F_PROC_ROLLBACK_GRANULES` |
| 初值 `b_a0` | 六面校正值 | 初值越准，启动暂态越小 |

### 6.2 零速修正

```c
if (gate->is_static) { v_n[0]=v_n[1]=v_n[2]=0.0f; vel.zupt = 1; }
```

- **位置不清零** —— 否则会把真实位移抹掉。
- 这是唯一能把位置误差按住的机制：误差不跨静止段累积。
- 若要长期静止下位置也不漂，需另加"确认无位移"的条件（例如只在 ZUPT 连续 N 秒且
  加速度计水平残差 < 阈值时，对 p 做慢牵引），**不要无条件清零**。

### 6.3 可选量测更新

| 参考 | 观测量 | 作用 |
|---|---|---|
| 磁力计 | 航向 | 抑制 yaw 漂移 |
| 气压计 | 高度 | ZUPT 只管水平 |
| GNSS | 位置/速度 | 唯一能长时间按住位置的手段 |

## 7. 误差预算（10 s 尺度）

| 误差源 | 量级 | 10 s 位置贡献 |
|---|---|---|
| 陀螺倾角随机游走（实测 N_eff = 0.58 deg/√h） | 10 s → 0.031° | **0.14 m** |
| 加速度计零偏 **不牵引**（20 mG，未标定典型值） | 0.196 m/s² | **9.8 m** |
| 加速度计零偏 **牵引后**（残余热漂 ~1 mG） | 0.0098 m/s² | **0.49 m** |
| 加速度计噪声（待实测） | ? | ? |
| 量化 1 LSB | 122 µg | 可忽略 |
| 积分法误差（梯形 vs 矩形） | ∝ a·dt² | 可忽略 |

**结论：不牵引时加速度计零偏压倒一切（9.8 m / 10 s）；牵引后降到与陀螺倾角项同量级。
所以 §6.1 不是可选项，是必需项。** 但这也意味着**牵引之后，天花板就变成陀螺的倾角随机游走了** ——
加速度计再准也压不下去。

## 9. 上报与记录

现有 4 路四元数**保持不动**（工具链 `cap.py` / `cap_read.py` / `turn360.py` 依赖它）。
追加通道并**降频**：

| 段 | 通道 | 说明 |
|---|---|---|
| 0–3 | q = w,x,y,z | 不变，20 B 帧 |
| 4–6 | a_mps2[3] | 校正后比力 |
| 7–9 | lin_accel_n[3] | 去重力后（静止时应 ≈ 0） |
| 10–12 | vel_n[3] | 导航系速度 |
| 13–15 | pos_n[3] | 导航系位置 |
| 16 | temp_celsius | 温度（判热漂必需） |

17 路 × 4 + 4 = **72 B/帧**。8 kHz 下 576 kB/s —— 主机记不住，必须分频：

| 上报率 | 带宽 | 8 h 体积 |
|---|---|---|
| 8 kHz | 576 kB/s | 16 GB |
| 1 kHz | 72 kB/s | 2.1 GB |
| **100 Hz** | **7.2 kB/s** | **207 MB** |

建议加一个 `justfloat_report()` 前的分频计数器，默认 100 Hz，调参期可临时提到 1 kHz。
（`tools/calib/cap.py` 现有的主机侧分频只是权宜 —— 它在 8 kHz 全速流上丢弃 99%，
USB 带宽和主机 CPU 都在白烧。）

## 10. 验证方案

| # | 方法 | 检验什么 | 判据 |
|---|---|---|---|
| 1 | 静止长记录 → Allan | 加速度计噪声/零偏 | 与陀螺同级；`a_lin` 静止时应 ≈ 0 |
| 2 | 六面 + 倾斜姿态 | 标度/交叉/零偏 | 残差 < 1 mG |
| 3 | **直线导轨推已知距离** | 标度 + 积分 | 净位移误差 < 1% |
| 4 | **往返闭合**（推出去再推回来） | 标度误差（灵敏） | 末态位移 ≈ 0，与陀螺整圈同思路 |
| 5 | 静止 → 机动 → 静止 | ZUPT + 牵引 | 每次静止后 v = 0，位置不跳变 |

**建议实施顺序（每步都能独立验证，不要一次全上）**

1. 只做"加速度校正 + 比力 + 去重力"，把 `a_mps2` 和 `lin_accel_n` 报出来。
   静止时 `lin_accel_n` 应该就是零偏+噪声 —— **这一步就能验证标定和去重力对不对**，
   不需要积分就能发现问题。
2. 加零偏牵引，看静止时 `lin_accel_n` 的长期漂移是否降下来。
3. 加积分 → v、p，但**先不上 ZUPT**，看纯惯导的漂移是否与 §7 预算吻合。
4. 加 ZUPT，验证每次静止速度归零。
5. 上导轨做 §10 的 3、4。
