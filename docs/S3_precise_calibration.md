# S3：高精度标定（三轴陀螺 K + 磁 A/C 重标 + 零偏预校正接入）

> 阶段定位（见 `ekf_native_gate_design.md` §6）：S3 = 高精度标定；GPS 融合顺延 S4。
> 本轮唯一外部基准：**能精确转 360° 的夹具**（实测：轴线对准体系 −y 仅 **0.16°**、整圈重复性 **0.56°**、单圈 12 s 匀速 33 dps、无削顶）。
> 目标：把 `k_s` 与交叉轴从"含耦合的 0.002"降到干净值，把磁 A/C 的倾角基准与方位基准钉死。

## 1. 要录的数据（一批，约 3 分钟）

夹具把器件夹好（朝向固定，记下哪个体轴竖直），每个动作**前面静置 ≥6 s、后面静置 ≥6 s**，转速约 **10~30 dps**（**不得削顶**，即 |ω| < 1990 dps 且 <1000 dps 更佳）：

| # | 动作 | 命令角 | 用途 |
|---|---|---|---|
| 1 | 绕夹具轴 **+360°** | +360.000° | 标度 + 对称交叉轴 |
| 2 | 绕夹具轴 **−360°** | −360.000° | **分离"轴线对准误差"与"标度误差"**（奇偶分离，必需） |
| 3 | 反转器件朝向（如原来 −y 竖直，改成 +y 竖直）后重复 +360° | +360.000° | 第二轴 |
| 4 | 同朝向 −360° | −360.000° | 第二轴奇偶分离 |
| 5 | 再转 90° 装夹后重复 +360° | +360.000° | 第三轴 |
| 6 | 同朝向 −360° | −360.000° | 第三轴奇偶分离 |

- 三轴的**方向不要靠猜**：每次装夹后先静置 30 s，用重力方向（加计）判出哪个体轴竖直，写进记录。
- 每条录像记下：文件号、夹具朝向说明、命令角（±360.000°）。
- 若夹具能连转多圈更好（例如 +720°）：把重复性噪声（0.56°）按 √N 压下去，标度精度可到 **~50 ppm**。

## 2. 陀螺标定的数学（要解什么）

固件现有校正链（`proc_gyro_bias.c`）：

```
dv[i] = (lsb[i] - bias[i]) / LSB_PER_DPS[i]        // 逐轴标度
gyro_dps[i] = dv[i] + K_i·dv[j] + K_i·dv[k]        // 对称交叉（KXY/KXZ/KYZ）
```

把它写成矩阵：**ω_meas = S · ω_true**，其中 S 含 3 个逐轴标度 + 3 个对称交叉（共 6 参数）。
我们要的是**逆映射 C = S⁻¹**（即"测量 → 真值"的 9 参数矩阵，再按对称性约束成 6 参数）。

对一次绕**固定轴** â、转过 θ 的旋转：ω_true(t) = â·θ̇(t) ⇒ ∫ω_true dt = â·θ。
于是对三条（或六条）录像，把每次的陀螺积分向量 m(k) = ∫ω_meas dt 排成矩阵：

```
[ m(1) | m(2) | m(3) ] = C · [ â₁θ₁ | â₂θ₂ | â₃θ₃ ]
⇒ C = [ m(1)|m(2)|m(3) ] · diag(1/θ₁, 1/θ₂, 1/θ₃) · [â₁|â₂|â₃]⁻¹
```

- **+θ 与 −θ 成对**使用：`C` 的**对称部分**（标度 + 交叉）在 ± 下同号，而**夹具轴线对准误差**（反对称部分）在 ± 下反号 ⇒ 两式相加/相减即可**分离**二者。这正是 0.16° 对准误差（= 440 ppm）不会污染标度拟合的原因。
- 拟合后输出：
  1. **逐轴标度误差（ppm）**：`diag(C) − 1`；
  2. **对称交叉轴 KXY/KXZ/KYZ**（写入 `v5f_tune.h`，替换现有常数）；
  3. **反对称部分 = 夹具轴与体轴的对准差**（独立核对上面 0.16° 的量级）；
  4. **残差**：每条录像 `||C·m − âθ|| / θ` ⇒ **验收线 ≤ 100 ppm（0.036°）**，成对一致性 ≤ 50 ppm。

> 与现有"手转精确 90°"法相比：那个受人手 0.05% 精度限制；本方法用夹具的 360° 与 ± 成对，目标 **50 ppm** 级，且**顺带给出交叉轴**（现有 K 值来历不明）。

## 3. 磁 A/C 重标（用夹具的精确角当方位基准）

关键改动：**姿态参考不再用陀螺积分，而用夹具的命令角**（消除陀螺标度/滞后白噪的一切影响）。

- **倾角基准**：加计（工厂椭圆标定）——注意本轮已排除"运行时牵引带偏"（贡献仅 0.022 g ≤1.1°），但为保证干净，标定时可用 `V5F_ACG_ALIN_*` 门使牵引只在准静时更新。
- **方位基准**：夹具命令角（每隔 45° 或 90° 停一次，每停 ≥6 s；或用整圈匀速 360° 的时间-角度映射）。
- **约束**：拟合后必须满足 **dip = 54.330 ± 0.5°（WMM）**；`det(A) < 0`（已验手性）；`|y|` p1~p99 ⊂ [0.99, 1.01]。
- **验收（沿用台账四条判据）**：① dip；② 偏航斜率 ≈ +1.0；③ 已知航向残差（摆幅 ≤1.5°）；④ dip 与倾角/朝向无关（摆幅 ≤1.5°）。
- **输出**：新的 `V5F_MAG_A_INIT` / `V5F_MAG_C_INIT` → 打 VER=118（`patch_magAC.py`，备份进 `bak_src/`）。

## 4. 零偏预校正接入（与 S3 同批做）

- 对齐时**单向播种**：`IX_BG ← gyro_bias_dps`（追踪器值），`P0_bias ← 追踪器历史散布`；之后 EKF 独占，**不连续注入**。
- 陀螺来源改为**追踪器校正后的 `imu.gyro_dps`**（含零偏 + 逐轴标度 + 交叉轴），`g0` 降为冷启动兜底。
- 结果：`σ_b0` 由 0.05 dps 降到 ~0.005 dps ⇒ 偏航交叉点 `t* = σ_m/σ_b0` 从 40 s 拉到 **~400 s**；`k_s` 干净后 `θ_rot* = σ_m/k_s` 从 1000° 拉到 **2000~4000°**。

## 6. 验收总表（S3 完成定义）

1. 陀螺：六圈残差 **≤100 ppm**、± 成对一致性 ≤50 ppm、交叉轴写入并复测通过；
2. 磁：四条判据全过，dip **54.33±0.5**，方位残差摆幅 **≤1.5°**；
3. 零偏：单向播种生效（`IX_BG` 初值 = 追踪器值、`P0_bias` = 其散布），磁中断 60 s 保持漂移 **<0.5°**（决定 `σ_b0` 是否诚实）；
4. 台账更新：`mag_calibration_log.md` 增 VER=118 行 + 本文件回填实测数字。
