## 2. 主路径定义（本记录中"合格"的适用范围）

**主路径 = 中低速 + 重力始终可用（|acc|≈1 g）+ 地磁自参考。**
剧烈运动（|acc| 数 g、无有效重力）与长段无参考运动属于**极限工况**，只作为边界验证，不作为主路径设计依据。

---

## 3. CDC(EP2) 接口与实测速率

* 载荷：`[w][x][y][z]` 各 float32 小端 + 帧尾 `00 00 80 7F`，**20 B/帧**，每个 IMU 帧发一次（名义 8 kHz）。
* **实测有效姿态更新率 351~352 Hz**（流是 8 kHz 的阶梯，同一值重复 ~23 帧）；步长与角速率自洽
  （p50 0.885°×352 Hz ≈ 310 dps ≈ 实测窗速率），说明**无跳变、无丢帧**。
* 新格式**无版本指纹**（`fw_tag` 随 162 通道一起关闭）；核对版本需看 `v5f_tune.h` 或旧格式。
* 旧格式（`CDC_QUAT_ONLY=0`）：`A5 5A | len(u16 LE=0x0288) | 162×f32 | 5A A5` = 654 B。

## 4. 验收方法（三套，互补）

| 方法 | 需要 | 给出的量 |
|---|---|---|
| A 有参考闭环 | 起止同一朝向（人工重复性 ~0.2°） | 起止差 ÷ 路径 |
| B 无参考暂停平台 | 运动中夹 ≥3 s 真静止平台 | 平台内 Δ总角 = 该次运动留下的残差；残差 ÷ 前段路径 |
| C 静止本底 | 同上 | 平台内帧间抖动 p99 |

**路径定义**：逐帧四元数角增量之和 `Σ|Δθ|`（不要用"只对更新帧取相邻帧"的近似，会少算 10%~13%）。

## 5. 实测结果（两份 JustFloat 日志）

| 项 | `..._061641_858`（无参考、高速） | `..._061843_305`（常规工况） |
|---|---|---|
| 帧数 / 时长 / 平均速率 | 167854 / 20.80 s / 8068 Hz | 92370 / 11.41 s / 8098 Hz |
| 坏帧（格式/帧尾） | 0 | 0 |
| \|q\|−1 p99 | 1.15e-7 | 1.14e-7 |
| 窗速率(0.15 s) p50 / p90 / p99 / max | **233.9** / 743.7 / 1105.6 / 1410.1 dps（>100 dps 占 65.2%） | **1.1** / 365.3 / 653.9 / 911.8 dps |
| 路径 Σ\|Δθ\| | **8174°** | **1892°** |
| 平台内残差（偏航/倾角） | 2.328°（+2.312 / +0.224），前段 8016° → **290 ppm** | 1.495°（+1.449 / +0.403），前段 1614° → **926 ppm** |
| 起止差（偏航/倾角） | 0.40°（−0.39 / +0.07） | 0.08°（+0.04 / +0.09） |
| 平台内抖动 p99 | 0.045° | 0.045° |

### 5.1 无参考 ppm 的两项分解

以两组（残差, 路径）拟合 `残差 = a + k·路径`：

```
k = (2.328 − 1.495) / (8016 − 1614) = 1.30e-4 °/°  →  130 ppm（路径比例项）
a = 1.495 − 130e-6×1614          = 1.29°           →  与路径无关的平台项
```

**结论：运动中的偏航误差不是随路径线性累积，而是"陀螺漂移 ↔ 磁牵引"的平衡平台（~1.3°）。**
路径越长平台被摊薄越多，ppm 才越小 —— 所以**无参考 ppm 必须同时给出路径长度**，否则 290 与 926 看似矛盾。

### 5.2 有参考口径的分辨力上限

人工重复性 0.2° ⇒ 可认证上界 = (起止差 + 0.2°) / 路径：

* 061641：≤ (0.40+0.2)/8174 = **73 ppm**
* 061843：≤ (0.08+0.2)/1892 = **148 ppm**

## 6. 验收结论（建议写入验收记录的口径）

```
有参考（闭环、起止同朝向）：  60 ppm 级（可认证上界 73~148 ppm，受 0.2° 人工重复性限制）
无参考（暂停平台法）：        路径比例项 130 ppm ＋ 与路径无关的平台项 1.3°
                             实例：8016° 段 → 290 ppm ；1614° 段 → 926 ppm
                             代表值取长段 ≈ 290~300 ppm，并注明路径长度
静止本底：                    平台内抖动 p99 = 0.045°
```

**判定：合格**（主路径）。依据：常规工况闭环 42~49 ppm（原始起止差 0.08°/1892°），平台残差里 95% 是偏航且可在 1.4~2.5 s 内收敛，静止本底 0.045°。

## 7. 遗留问题与下一步

1. **平台窗污染**：本轮用"窗速率 < 1.5 dps"切平台，窗口头尾会吃进运动尾巴/开头
   （`061843` 平台#1 的"5.05°"实为运动开头；平台#2 前 0.3 s 的 12.1° 是运动尾）。
   → 需要一次 **`CDC_QUAT_ONLY=0`** 的同动作录制，用陀螺精确切"真正停住"那一帧。
2. **无参考无单一 ppm 值**（见 5.1）：记录必须带路径长度。
3. **极限区 R**：`MAG_TILT_CAP_DEG=10°` 为暂定宽松值，等专门数据再定；它只在 σ_tilt>10° 时起作用，
   对主路径惰性（主路径 σ_tilt 仅 0.4~2°）。
4. **主路径权限瓶颈**：`MAG_K_MAX=0.015`（三级类别实测 99.7~100% 顶在钳位上）。
   是否抬到 0.03 待定；判据应为"主路径闭环不变差 + 静止段更快收敛"。
5. **陀螺削顶**：ICM-42605 物理上限 ±2000 dps；削顶会在运动中丢失姿态信息
   （实测削顶 2703 帧/337 ms 时，旧链 att.q 停后偏差 12°、EKF 1.65°，且 att.q 需 ~13 s 恢复）。
   VER=97 起 bit12~15 记录削顶，**配置层面无法再扩量程**。
6. **上位机切帧缺陷**：旧 162 通道格式有 1.9~2.7% 的帧被按帧尾重同步切错（载荷字节组合触发），
   属上位机/传输侧问题，非固件；分析时按 tag 列过滤。
7. **日志陀螺不可离线复算**：`col26-28 × col25(µs)` 复现不出固件的陀螺积分（差 ~8%，闭环下放大到 175°）→
   离线只能用固件算好的 `att.q`，不要自己重积。

## 8. 已作废的分析（避免重犯，如实记录）

* 用 `att.q` 当**偏航真值**去归因 EKF 误差 → **作废**：旧链偏航误差本身可达 39~45°（无偏航观测，修不掉）。
* 用"重力+磁场正交三元组"当 **ppm 参考** → **作废**：手部/环境扰动能把场方向带偏 25°。
* "**转动期禁磁**"提案 → **被闭环数据否掉**：剧烈运动段磁是唯一把偏航钉住的机制，关掉会让 EKF 偏航跟着陀螺漂到数十度。
* 早期分析脚本把 `col25`（µs）误按 10 ns 系数 `1e-8` 积分（实际应 `1e-6`）→ 由此得到的
  "纯陀螺闭合 1.84°/3.08°"、"陀螺 60~300 ppm"等结论**全部作废**。
* 削顶帧做"反事实插值"重建真值 → 作废（真值在削顶方向之外，插值无意义）。
