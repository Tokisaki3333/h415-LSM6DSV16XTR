## 2. ★ 错误清单（本阶段我真实犯过 / 险些犯下）

### M1 —— 把 `|B|` 的模长起伏当成"地磁误差"或"环境场梯度" ❌

**我当时的推理**：图上 `|B|` 在运动段有 ±7~8% 的大幅摆动 ⟹ 地磁在运动中不可用。

**为什么错**：**模长起伏不代表角度误差。** 地磁的角度精度是典型 **±0.5°、且与速度无关**（先前实测）。模长会被以下因素改变而角度不受影响：传感器在非均匀场中平移、运动引起的真实场扰、乃至标定残差。

**正确口径**：
```
只用【方向】：v = mag_vector(...);  v /= |v|
模长可以完全丢弃，不进入任何误差量。
判据用【角度】，不用【模长】。
```

---

### M2 —— 把磁-姿态残差里的 18° 归因于 MMC 的"10 ms 测量延迟" ❌

**我当时的推理**：MMC 一次测量 10 ms，2000 dps 下就是 20°，正好解释观测到的 18° 振荡。

**为什么错**：**MMC5983MA 一次测量只要 0.5~1 ms。** 1 ms @2000 dps 只有 **2°**，两个数量级都不够。

**而且实测直接否掉了"存在时差"这个前提**（见 M5）：Δτ 扫描在 [0, 1 ms] 上**单调上升、无谷底**，最优就是 Δτ=0。

**教训**：**先用已知量级做上限自检**。任何"解释"如果要求某个参数比器件手册差 10 倍，先怀疑解释本身。

---

### M3 —— 拿磁的**净转角**去比陀螺的**路径长度** ❌

**我当时的推理**：`Σ|ω|dt`（陀螺）vs 磁的每样本转角，比值 0.64~0.88 ⟹ 磁在高转速下漏读 30%。

**为什么错**：磁测到的是**净转角 `|∫ω dt|`**，而我算出的是**路径长度 `∫|ω|dt`**。翻滚时**转轴自身在转（锥动）**，路径必然 ≥ 净转：

```
路径 ∫|ω|dt  ≥  净转 |∫ω dt|     等号仅在转轴固定时成立
⟹ 比值 < 1 是锥动的【必然结果】，不是漏读
```

**正确口径**：要比就比同一种量——**陀螺必须取矢量积分的模 `|Σ ω·dt|`**，不是标量积分的 `Σ|ω|·dt`。

---

### M4 —— 以为"套上椭球矫正"能压掉模长起伏 ❌

**我当时的推理**：B 做过椭球矫正，所以起伏是没套软磁矩阵造成的。

**为什么错**：实测椭球**各向异性只有 0.4%**（Q 对角 1.4727/1.4607/1.4715e-8），交叉项 0.5~0.7%。**套上去最多改 0.4%，差 20 倍**，解释不了 ±7~8%。

**另一层**：`magmap.to_gauss()` 本来就**只做硬磁**（逐相球心 `(m − center)/16384`）。这不是缺陷——**C4 的实测结论是分相各减自己球心后残差 0.678%/0.700%，已经够了**；软磁项小到不值得引入。

---

### M5 —— "磁样本与帧姿态有固定时差"（陷阱：无谷底时不要硬凑）⚠

**这个方向本身是对的**（值得测），错的是**结论的读法**。

```
正确做法: 对每个磁样本做 q_true = q[j] ⊗ exp(−ω[j]·Δτ)，扫 Δτ 使 b_nav 最稳
实测结果: Δτ = 0.00 ms → 运动 RMS 2.5920°   （最小）
          Δτ = 0.50 ms → 运动 RMS 2.7360°
          Δτ = 1.00 ms → 运动 RMS 2.8327°   （最大）
          ⟹ 单调上升，无任何极小值
```

**正确的读法**：**无谷底 = 对齐量本就是 0 = 磁样本与帧姿态本来就对齐**。
**错误的读法**（要避免）：因为曲线在边界最小，就去扫描负 Δτ 或扩大范围，硬找出一个谷底。
**单调 + 边界最优 ⟹ 结论就是"无需补偿"。**

---

### M6 —— 量级自检缺失会直接产出荒谬数 ⚠

我在修 M3 时写了个有 bug 的矢量积分，**1.3 ms 内算出 157° 的净转角**。

**自检规则（务必执行）**：
```
任意区间的净转角  ≤  |ω|max × Δt
   本例上限: 2500 dps × 1.303 ms = 3.26°
   ⟹ 算出 157° 就是实现错误，不要往下解读
```
**任何物理量先算它的上限，超了就回头查代码，不要写进结论。**

## 3. 正确工作流（照抄即可）

```python
import sys; sys.path.insert(0, '.')
import numpy as np, magmap

fr = magmap.Frames(path)                       # 跳 8192 B；按字节判别布局；168 ⟹ layout_v=4

# ★ calibrate 返回【元组】，不是单个对象
cal, info = magmap.calibrate(fr, prefer='SET')
#   cal['SET'] = PhaseCal(n=…, R=…, 残差=…%, 转轴可辨识=…, cov比=…)
#   info      = {'n_set':…, 'n_rst':…, 'rst_usable':…, 'primary':'SET'}
R = cal['SET'].radius_gauss                    # ★ 属性，不要加括号

# 只取【新磁样本】的帧（C9 卡死判据）
m = fr.new_mask(); idx = np.where(m)[0]
raw = fr.mag[m]; polm = fr.pol[m]              # pol: 0 = SET, 非 0 = RST

for k in range(len(idx)):
    try:
        v, degraded = magmap.mag_vector(raw[k], polm[k], cal, strict_phase=True)  # ★ 也返回元组
        v = v / np.linalg.norm(v)              # ★ 只留方向（M1）
    except Exception:
        continue                               # 该相未标定 ⟹ 跳过，绝不用另一相顶替（C4）

# 地磁当绝对基准量陀螺残差:
#   b_nav = R(q_eskf) · b_body_unit
#   err   = angle(b_nav, mean(b_nav))        ← 这条曲线就是"陀螺残差"
```

**必须遵守的旧约束**（`magmap.py` 文件头，不要绕开）：
```
C1 跳开头 8192 B
C4 绝不用 (m_SET + m_RESET)/2 当零点；两相是两个不同心球（球心距 3588.2 counts = 场强 43.15%）
C5 零点必须逐录制解，不能沿用常量（SET 相球心跨录制 x 差 38、y 差 204 counts）
C6 偏航录制的转轴分量先天不可辨识 ⟹ 用 axis_known=False 标出，倾角不可信
C7 RST < MIN_RST(100) 时只能 SET-only
C9 卡死判据：新磁样本 = mmc_cnt 递增
```
