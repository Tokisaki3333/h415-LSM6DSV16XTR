## 一、必要性（实测结论：**弱，且不在"慢漂"上**）

| 判据 | 实测值 | 含义 |
|---|---|---|
| 同录制前后半 SET 球心差 | **1.11°**（158.6 counts），拟合残差 122.3 counts ⟹ 比值 **1.3** | 零点确实在动，但只略高于拟合噪声 |
| 跨录制 SET 球心散布 | 中位 **0.75°**，max **2.83°** | 会话间变化小 |
| 地磁自身精度 | γ σ = **0.737°** | 标尺 |
| 离线常量 vs 六面金牌标准 | **0.82°** | 已足够好 |

**⟹ 结论：**
1. **离线预标定已把零点做到与地磁自身噪声同量级** ⟹ 在线标定跟随慢漂的**边际收益只有 ~1° 量级**；
2. **在线标定真正的价值是【捕捉阶跃变化】**：新增磁体 / 换装夹 / 换外壳 / 换电池
   ⟹ 硬磁可能**跳变**数十度，这类变化离线常量无法预知；
3. **⟹ 因此设计目标不是"更激进的跟踪"，而是"有充分证据才动的、带锚定的慢跟踪 + 跳变告警"。**

**❌ 已否证、禁止使用的必要性论据**（见信任登记表 §3-D）：
"换摆位硬磁可达 27°"。恒定体坐标硬磁产生的是**随航向的正弦误差**
`δψ ≈ (c_⊥/|B_h|)·sin(ψ−φ)`，不是摆位改变硬磁。

## 二、在线数据能标定什么（可辨识性，实测）

**方法（不用姿态）：** 机体系磁场单位向量 `N_i=(m_i−c)/|m_i−c|` 的
局部可辨识矩阵 `M = Σ N_i N_iᵀ`，其特征值 `λ1≥λ2≥λ3` 即各方向被激励的强度。

| 工况 | mz 跨度 | λ3/λ1 | 可辨识性 |
|---|---|---|---|
| `230659` 纯水平慢转 | **139~328 counts** | **0.0000~0.0024** | 竖直方向**不可辨识** ⟹ `c_z` 与 `A` 的 z 行不可辨识 |
| `234141` 含翻滚（良好窗口） | 16178 | 0.14~0.55 | 三维可辨识 |
| 六面整圈（全姿态） | 16178 | 0.11~0.19 | 三维可辨识 |

**⟹ 可标定 / 不可标定清单：**

| 量 | 正常工况（不大的姿态运动） | 依据 |
|---|---|---|
| **水平子空间的零点分量**（⊥ 重力锥轴） | ✅ 可标定 | λ1,λ2 被激励 |
| **沿重力/锥轴的分量 `c_z`** | ❌ **不可标定** ⟹ 必须冻结 | λ3/λ1 ≤ 0.0024 |
| **9 参数椭球（含 z 行尺度与交叉）** | ❌ 不可标定 | 需全球面激励 |
| **RST 相零点** | ❌ 不可拟合（1024:1 下仅 15~91 样本） | 信任登记表 §2 |
| **两相混用** | 🚫 **禁止**（两相球心距 3588 counts = 43% 场强） | §3-A |
| **观测量 `|m−c| = |B|`** | ✅ 免姿态、非循环 | 物理恒定事实 |

## 三、在线标定目标（设计）

> **⚠ 阅读顺序警告：§三 与 §四点五 是中间过程稿。其中"样本准入门"里的
> `|ω|` 门已被 §7.1 审计判定为【有害】（与姿态强相关，引入 3800~9100 counts 偏置），
> §7.3 已正式取消。**
> **最终权威结论在 §七（7.1~7.4）。引用请以 §七 为准。**

### 3.1 目标（按优先级）

```
G1【主目标】在【可辨识子空间】内在线修正 SET 相零点 c_SET，
            未激励方向【严格冻结】在离线先验 c_off 上。
G2【副产物】在线给出 |B|（场强）及其散布 —— 作为标定质量与"磁场环境变化"的健康指标。
G3【告警】 |B| 或拟合残差出现【阶跃/持续超限】时给出"需重标"告警（捕捉阶跃变化）。
G4【门控】 SET-only + 准静态 + |a|≈1g 的样本准入（见 §3.3）。
```

### 3.2 算法：子空间约束的递推球拟合（已在真实数据上验证）

```
观测量（免姿态）：  |m_i − c| = |B|           （物理事实，与姿态无关 ⟹ 非循环）

滑窗 W（建议 30~60 s 或固定样本数）内：
  1) 一次无约束球拟合得 c0，取法向 N_i = (m_i−c0)/|m_i−c0|
  2) 局部可辨识矩阵  M = Σ_i N_i N_iᵀ ，特征分解得 λ(升序), V
  3) 取可辨识基  B = V[:, λ_k ≥ rel_thr·λ_max]      （rel_thr 建议 0.10）
  4) 令 c = c_off + B·α ，代回球方程 |m|² = 2c·m + b（对 c 线性）：
         min_{α,b}  Σ_i ‖ |m_i|² − 2(c_off+Bα)·m_i − b ‖²
     ⟹ 精确最小二乘（无迭代、无姿态）
  5) 输出 c；并把 (λ_max/λ_min, B 的维数, 残差 RMS, |B|) 作为置信度与告警输入
```

**★ 这个形式的三个关键性质（均已数值验证）：**

| 性质 | 说明 | 实测 |
|---|---|---|
| **不可辨识方向自动冻结** | `B` 只含激励足够的特征向量 ⟹ 沿锥轴的分量**根本不出现在参数里** | `230659`: 与先验差 **119~342** counts（对比弱标量正则的 7500~9700，改善 **20~80 倍**） |
| **激励充分时自动退化为全参数** | 三轴都被激励 ⟹ `B` 取满 3 维 | 六面: 取 3 维，收敛到 magmap 球心 **36~71 counts = 0.25~0.49°** |
| **维度随窗口自洽切换** | 窗口退化时降维、恢复时升维 | `234141`: 1 维 ⇄ 3 维自动切换 |

### 3.3 样本准入门（四道）

```
① 极性: 仅 SET（pol==0）。RST 样本一律丢弃 —— 两相球心距 43% 场强，混用即灾难。
② 速率: |ω| < W_MAX（建议 25~50 dps）。理由：磁与姿态的配准受上报栅格限制，
        |ω|=50 dps 下配准误差约 0.15°（该限制的定量来源见 S3 协议，但该文档未验证，
        故此处以"宁严勿松"取值）。
③ 重力: | |a| − 1g | < 0.05（重力可信 ⟹ 姿态可信 ⟹ 样本可信）。
④ 场强: ||m−c| − |B|_ref| < 阈值（剔除被外部磁体污染或卡死的样本）。
```

### 3.4 更新策略：锚定 + 慢时标 + 阶跃告警

```
· 先验锚定: c 从 c_off 出发；c_off = 固件离线常量（已验证距六面金牌 0.82°）。
· 慢时标:   滑窗长度取 30~60 s；且对 c 的更新再加一阶低通（时间常数 60~300 s）。
           理由（§3-I）：真实慢漂只有 ~1°，不需要快跟踪；快跟踪只会放大噪声。
· 死区:     当 |Δc| 小于噪声当量（约 0.3~0.5°）时不写回，避免抖动。
· 阶跃告警: 当 |B| 中位相对基线偏移 > 1.5%（各录制实测散度中位 1.606%），
           或拟合残差 RMS 持续 > 2 倍基线 ⟹ 置"需重标"标志，而不是自动大改 c。
           （阶跃变化用告警+重标，比让在线估计器去追更安全。）
```

### 3.5 明确不做（Non-goals）

```
✗ 不做 9 参数椭球在线拟合  —— 需全球面激励，正常工况不可辨识（§二）
✗ 不做 RST 相零点在线拟合  —— 1024:1 下样本 15~91 个，不可拟合（§二）
✗ 不做两相混用/中点零点    —— 信任登记表 §3-A/§3-D 已否证
✗ 不追慢漂（>0.5°/min 的响应没必要）—— §一 显示边际收益仅 ~1°
✗ 不用姿态当观测基准       —— 循环论证（信任登记表铁律）
```

## 四点五、自陷点分析与精度预算（2026-10-14 补充，关键）

### A. 为什么"弱可辨识方向"绝不能"勉强标定"

```
严格冻结: 该方向根本不在参数里 ⟹ 保持离线先验 ⟹ 误差 = 先验误差（已实测 0.82°）
勉强标定: 该方向在参数里但信息量不足 ⟹ 解由噪声/病态决定 ⟹ 误差可任意大，
         且会反过来污染下一拍的可辨识结构与门控 ⟹ 【自陷】
```

**实测证据（本设计的递推版，`t3f_recursive.py` 第一版）**：
`c` 从 `[129652 131607 131318]` 发散到 `[-236742 120596 285388]` 并**稳定停在那里**。
这就是自陷点的活体标本：`c` 错 ⟹ `N=(m−c)/|m−c|` 错 ⟹ 基 `B` 错 ⟹ 解出的 `c` 更错。

### B. 反馈回路穷举与切断（自陷源清单）

| 回路 | 路径 | 状态 | 切断方式 |
|---|---|---|---|
| A | `c` → `N=(m−c)/\|m−c\|` → 基 `B` → 解 → `c` | **实测自陷** | 基的参考**固定为 `c_off`**，禁止用当前 `c` |
| B | `c` → 门控 `\|\|m−c\|−\|B\|\|` → 样本集 → 解 → `c` | 隐患 | 门控用固定先验 `c_off`，带宽取宽（±5%） |
| C | `c` → 残差 → 置信度 → 更新率 → `c` | 隐患 | 更新率固定，不由残差自适应 |
| D | `c` → ESKF → 姿态 → 磁处理 → `c` | **天然切断** | 观测量只用 `\|m−c\|=\|B\|`，**不含姿态** |
| E | `c` → ESKF → 重力门 → 样本集 → `c` | **天然切断** | 门控用**原始加计**，不经 ESKF |

**⟹ 安全设计的硬条件：A 必须切；B/C 必须显式断开；D/E 由"免姿态"天然满足。**

```

  ⟹ 单靠子空间约束【不够】，限幅才是最终安全网
· ⟹ 因此还需第三道：激励准入
     要求 λ1/M（归一化激励强度）超过阈值，否则【本窗不产生任何更新】
     典型: 000534(静止为主) 的 w3/w1≈0，应直接判"本窗不可标定"而不出解
```

```
① 极性门  : 仅 SET（pol==0）
② 样本门  : |ω|<50 dps 且 | |a|−1 |<0.05 且 场强带（用固定先验 c_off 判）
```

## 七、数据判决与最终设计（2026-10-14）

> **本节经过一次自我否证与重做。** 第一版（§7-旧）依据"在线校正量摆动且偏离离线值
> 2000~7000 counts"得出"关闭在线校正"。**该结论已被审计推翻**，原因是我自己的

### 7.1 【审计】为何曾得出"偏离数千 counts"——两个自身缺陷

**自洽性前提**：离线常量 `MAG_ZERO_*` 已验证距六面金牌 SET 球心仅 **118 counts = 0.82°**。
⟹ **任何正确的在线估计器都应落在离线常量附近（百 counts 量级）**；
若给出数千 counts 偏差，**必是实现有 bug**，不能归因于"激励不足"。

**逐级加功能的审计（`t3i_audit.py`）**：

| tag | V0 magmap(参照) 与c_off | **V1 朴素全样本** 与c_off | **V2 +样本门** 与c_off | V3 +子空间 与c_off |
|---|---|---|---|---|
| 六面整圈 | 118.7 | **118.7（与V0逐位相同）** | 121.1 | 121.1 |
| 230659 | 8544.1 | **8544.1（同V0）** | 8481.0 | **4.7** |
| 232607 | 342.3 | **342.3（同V0）** | 316.4 | 316.4 |
| 233844 | 151.9 | **151.9（同V0）** | **4859.2** | 786.2 |
| 234141 | 55.8 | **55.8（同V0）** | **3827.7** | 3473.9 |
| 235545 | 135.1 | **135.1（同V0）** | **9100.3** | 7978.6 |
| 000534 | 10.4 | **10.4（同V0）** | **8681.8** | 8522.0 |

**结论：**
```
缺陷① 【样本门有害】 V1（全部样本）与 magmap 逐位相同 ⟹ 数据口径与球拟合都对。
       加上 |ω|<50 dps 且 | |a|−1 |<0.05 的门后偏离 3800~9100 counts。
       根因: 该门是为【姿态辅助拟合】准备的（那才需要姿态准）；
             而本设计是【免姿态】的（只用 |m−c|=|B|），磁计数在任何转速下都有效。
             ⟹ 该门既无必要，又因筛出的样本与姿态强相关而引入严重偏置。
缺陷② 【窗太短】 切 12 窗（每窗 ~8%）时 σ|Δc| 达 2200~5200 counts；
       窗加长到 ≥30% 后降到 27~110 counts。
```

**两条硬结论（取代 §7-旧）：**

### 7.3 最终设计（修订版，取代 §四点五 与 §7-旧）

```
D0 【窗长】滑窗 ≥ 会话的 30%（或等价的长时标累积，时间常数 ≥ 数分钟）。
       理由: §7.2 —— 窗 ≥30% 才收敛；短窗解是病态噪声，必须丢弃。
D1 【取消运动门】不做 |ω| 门、不做 |a| 门。
       理由: §7.1 缺陷① —— 免姿态估计器不需要，且会引入姿态相关偏置。
       仅保留: 极性门（仅 SET）。若需防"加计不可信"，只把它用在【健康判定】上，
       绝不用于筛标定样本。
D2 【覆盖率/激励门】用 λ1/M（归一化激励强度）判本窗是否可标定；
       不够则【本窗不出解】。用于挡掉 232607 那类纯平动、零转动工况。
D3 【子空间冻结】基 B 只取 λ_k ≥ 0.10·λ_max 的方向；不可辨识方向严格冻结在 c_off。
       理由: 实测 230659（纯水平旋转）下，这个约束把偏差从 8544 压到 4.7 counts（1800 倍）。
D4 【硬限幅】|Δc| ≤ 300 counts（≈3×收敛值）。超限 ⟹ 拒绝更新 + 告警。
D5 【无递推反馈】每窗独立求解，不跨窗累积状态。
       理由: 递推版实测自陷并发散到 −2e5（`t3f_recursive.py`）。
D6 【阶跃告警】若要捕捉"贴磁体/换安装"的阶跃，用 |B| 模长与残差判定并告警，
       不靠自动挪零点（阶跃期短窗解不可信，见 §7.2）。
```

### 7.5 【正面效果证明】收益存在但可忽略；且风险远大于收益（`t3k_benefit.py`）

**一致性只是最基本的交叉校验。** 要证明正面效果，必须比"用离线常量"更好。
姿态不可用作参照（循环），故用**免姿态判据**：模长一致性 `RMS(|m − c|)` ——
它就是球拟合的目标函数，`c` 越准残差越小，且完全不含姿态。

三种零点对比：`c_off`（固件离线常量）、`c_win`（在线算法，会话后半长窗）、
`c_rec`（该录制自身球心 = 逐会话 oracle = 在线标定的理论上限）。

**结论（三条，缺一不可）：**
```
B1 正面效果【确实存在】：oracle 可改善 0.047°，在线捕获 83%（0.039°）
   ⟹ 不是"估计器坏"，也不是"无信息"，是真的有一点点收益
B2 但收益【可忽略】：0.039° 相对地磁自身噪声 0.737° 只有 5%，
   相对离线零点折算的 1.69° 航向误差只有 2%
B3 而风险【远大于收益】：ARC12 一个实例就把方向当量从 1.86° 恶化到 5.9°（+4.1°）
   ⟹ 收益 0.04° vs 风险 4.1° ⟹ 风险/收益 ≈ 100 倍
```

**⟹ 工程结论：不做在线零点校正。** 固件现状（离线常量 `MAG_ZERO_*` + 不做在线零点跟踪）
是正确且安全的。理由不再是"估计器有 bug"（§7.1 已修），
而是**收益 0.039° 抵不上任何一点引入自陷风险的可能**。

**⟹ 若仍要做，则必须同时满足（否则风险>收益）：**
```
C1 激励门 λ1/M（挡掉 230659 那类竖直不可辨识、232607 那类零转动）
C2 质量控制门（挡掉 ARC12 那类 usable_for_calibration=False）
C3 收益门：只有当本窗估计与当前零点之差在 yaw 当量上 > 0.1°（> 噪声的 ~15%）才允许更新
C4 硬限幅 ±300 counts + 超限拒绝与告警（§7.3-D4）
```
