## 2. 器件驱动源码

**本仓库内的实现即驱动本身**，位于 `Common/Common/`：

| 文件 | 说明 |
|---|---|
| `lsm6dsv16x.c` / `.h` / `lsm6dsv16x_reg.h` | IMU 驱动 + 寄存器定义 |
| `mmc5983.c` / `.h` / `mmc5983ma_reg.h` | 磁强计驱动 + 寄存器定义 |
| `bmp388.c` / `.h` / `bmp388_reg.h` | 气压计驱动 + 寄存器定义 |
| `i2c_soft.c` / `.h`、`sensor_spi.c` / `.h`、`sensor_dma.h` | 总线层 |

**注意**：
```
1. 工程内未内置厂商的原始驱动【包】（ST 的 lsm6dsv16x-pid、MEMSIC 的 MMC5983MA
   参考驱动源码树）—— 本地未找到对应压缩包。
2. 若需逐寄存器核对，请以 docs/datasheets/ 的手册 + 仓库内 *_reg.h 为准；
   后者是从手册抄录的寄存器定义。
3. 磁强计的 SET/RESET 时序口径（官方驱动 AP_Compass_MMC5XX3 的做法）见
   docs/S2_地磁读法与阶段结论.md 与 docs/mag_calibration_log.md。
```

## 4. 引用纪律

```
1. 手册 > 仓库内 *_reg.h > 文档中的转述。
   凡"文档说器件如何"与手册冲突，以手册为准，并应修正文档。
2. 任何来自旧代器件的数字（ICM-42605 / IST8310 / MMC5603NJ）必须标注【旧代】。
3. 本目录只放官方/厂商资料。项目的分析口径、常数溯源、结论登记
   分别在 docs/接力_*.md、V5F/User/inc/proc_tune.h 注释、
   docs/地磁结论信任登记表.md 中，不要混入本目录。
```
