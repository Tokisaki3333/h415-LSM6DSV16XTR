# 偏航通道的时间尺度分解：陀螺短期精度 vs 地磁绝对基准（数学描述）

> 回答用户："这样也能提高陀螺仪短期内对偏航角的贡献？长时间后陀螺仪偏航角的 R 会很大，
> 但其短时间内相对运动精度仍远高于地磁，数学上如何描述这点？"
> 结论：**不能**。把 τ 调小（1.5 s）反而**破坏**陀螺的短期优势；正确的数学结构是
> "时间尺度分离 + 把地磁偏置当状态"，不是调 τ。

---

## 1 精确的误差模型（1 维偏航通道）

状态：真偏航 `ψ`；陀螺测量 `ω_m = ψ̇ + b_g(t) + n_g(t)`；地磁测量 `y = ψ + b_m(t) + n_m(t)`。

```
n_g : 白噪声，PSD = ARW²        [rad²/s]      （实测 ARW = 0.36 deg/√h = 0.0060 deg/√s）
b_g : 陀螺零偏，随机游走，谱密度 σ_bg           （实测 ~0.3 dps 常值 + 慢变）
n_m : 地磁白噪声，σ_m                          （实测创新 σ ≈ 0.33° ⇒ σ_m ≈ 0.3°）
b_m : 地磁偏置（标定残差/软硬铁），在任务时标上近似常值，量级 b_m ≈ 1~3°
```

积分后的误差方差（**关键公式**，`t` = 自上电/上次绝对基准以来的时间，`Δ` = 关心的短时段）：

```
Var[ ψ̂(t+Δ) − ψ(t+Δ) ]  =  P_ψ(0)        历史失配（上电/上次绝对基准）
                          + ARW²·(t+Δ)    白噪声积分
                          + P_bg·(t+Δ)²   零偏不确定性的一阶项  ← 实测主导项
                          + σ_bg²·(t+Δ)³/3 零偏随机游走
```

**两个时间尺度必须分开写**（这正是用户直觉的数学形式）：

```
总不确定度（绝对）  σ_abs(t)  = sqrt(P_ψ(0) + ARW²t + P_bg·t² + σ_bg²t³/3)      随 t 增长、无界
增量不确定度（相对）σ_inc(Δ)  = sqrt(ARW²·Δ + P_bg(t)·Δ²)                       与历史 P_ψ(0) 无关
```

⇒ **"P88 很大"只说明绝对偏航不确定，不等于陀螺变差**；短时相对运动精度只由 `ARW` 与
**当前**零偏不确定度 `P_bg(t)` 决定。实测（`imu_20260922_211657.bin`，300 s 静止）：

| 量 | 值 | 来源 |
|---|---|---|
| ARW | 0.0060 deg/√s | Allan(1 s) = 0.0060 dps |
| σ_abs(300 s) = 2.60° | ⇒ 若按 `P_bg·t²` 反解：`sqrt(P_bg) = 0.0087 dps`（31 deg/h） | col104 |
| **σ_inc(1 s)** = sqrt(0.0060² + 0.0087²) = **0.0105°** | 与 `P_ψ(0)`、与 300 s 的历史**无关** | 上式 |
| 地磁白噪声 σ_m ≈ 0.33° | 静态创新 ν = thm−thp 的 σ | §8.17 |
| 地磁偏置 b_m ≈ 1~3° | 标定残差（无外部基准不可测，见 §4） | 先验 |

⇒ **陀螺 1 s 的增量精度比地磁白噪声好 ~30 倍，比地磁偏置好 100~300 倍。**
这就是"长时间后 R 很大、短时间相对精度仍远高于地磁"的严格表述：
**总方差大（历史项）与增量方差小（当前项）是两件独立的事。**

## 2 KF 里"陀螺短期贡献"到底由谁决定（τ 的真实作用）

KF 的传播是**纯陀螺积分**：`ψ̂ ← ψ̂ + (ω_m − b̂_g)·dt`（增益 = 1，对所有频率）。
地磁只以修正项 `K·ν` 出现，`K = dt/τ` ⇒ 地磁对**增量**的注入率为

```
Δψ_inject(Δ)  =  b_m · Δ / τ                     （b_m = 地磁偏置，Δ ≪ τ）
```

⇒ **"提高陀螺短期贡献" ⟺ 让 `b_m/τ` 尽量小 ⟺ τ 要大**。
τ=1.5 s 时：`b_m/τ = 2°/1.5 s ≈ 1.3 °/s`，比陀螺 1 s 增量精度（0.0105°）**差两个数量级** ✗✗
——即 **VER=130 的 1.5 s 是把陀螺的短期优势主动扔掉**（换来地磁偏置以 1.5 s 常数进入姿态）。

反过来要求"地磁注入 ≪ 陀螺增量"：`b_m·Δ/τ ≪ σ_inc(Δ)`
⇒ 取 Δ=1 s、b_m=2°：**τ ≫ 190 s**。
但 τ≫190 s 又不行：陀螺**常值零偏 0.3 dps** 若只靠地磁消除，190 s 内会积 57° ✗✗。

⇒ **单靠一个 τ 无法同时满足两边**。这就是"上次降低前/后都不对"的根因。

## 3 正确结构：把两个偏置都变成**状态**（时间尺度由可观性结构决定，而非调 τ）

增广状态 `x = [ψ, b_g, b_m]ᵀ`：

```
传播:  ψ̇ = ω_m − b_g ,   ḃ_g = w_g (PSD σ_bg²) ,   ḃ_m = w_m (PSD σ_bm²)
观测:  y  = ψ + b_m + n_m ,   R = σ_m²        ← 只用**白噪声**，不留安全裕量
```

- 新息 `ν = y − (ψ̂ + b̂_m)` 的分配由**方差比**决定：
  `K_ψ = P_ψψ/(P_ψψ + P_bm + R)`，`K_bm = P_bm/(P_ψψ + P_bm + R)`（1 维、H=[1 1]）。
  - 取 `P_bm = (2°)² ≫ P_ψψ` ⇒ 新息几乎全部记到 `b̂_m` 上 ⇒ **`ψ` 不被地磁偏置直接污染**，
    而 `P_bm` 随时间被观测削小，地磁绝对基准以 `b̂_m` 的收敛速率（由 `σ_bm` 决定）缓慢接入 ✓
- **陀螺零偏 `b_g` 由状态估计消除**（0.3 dps 的漂移不需要靠地磁快拉）⇒ 短期运动完全保持陀螺精度 ✓
- 需要显式声明的**可观性事实**：1 维偏航通道里 `ψ` 的常值误差与 `b_m` **只以和的形式被观测**
  ⇒ 静止+纯 IMU/磁 时二者不可分辨；`b̂_m` 的收敛速度完全由先验 `P_bm(0)`、`σ_bm` 决定。
  要真正分离需要**外部绝对基准**（GPS 航迹/对地速度方向）或**已知运动**。

等价说法（频域）：陀螺误差谱 `S_g(f)` 在低频 ∝ `P_bg/f²` 上升、高频平坦 `ARW²`；
地磁误差谱 = 白噪 + 低频"偏置团"。最优（Wiener）权重 `H(f)=S_g/(S_g+S_m)` 只在
**低频**取地磁、**高频**全取陀螺；把 `b_m` 建模为 GM 过程（相关时间 `T_c`）后，
最优交界频率 `f_c` 与 `T_c` 同量级 ⇒ **交界时间常数 ≈ `T_c`（地磁偏置的相关时间）**，
不是 1.5 s，也不是 15.85 s。

## 4 对规范（`ekf_yaw_tau_spec.md`）的修正建议

1. **"静止 τ = 1.5 s"这个目标本身应作废**：它与"保持陀螺短期贡献"互相矛盾（§2 的不等式）。
   要么承认"地磁偏置以 1.5 s 常数进入姿态"，要么不要 τ。
2. **改为按可观性结构设计**：增广 `b_m` 状态（§3），`R = σ_m²`（白噪），
   时间尺度由 `P_bm(0)`、`σ_bm`、`P_bg(0)`、`σ_bg` 四个**物理量**决定 —— 每个都有单位、有实测口径、可验证。
3. **τ 只保留一个合法用途**：作为 `b_m` 的 GM 相关时间 `T_c` 的**等价物**（即"地磁偏置在被观测多久后允许改变"），
   并且必须写成 `Q_bm = 2σ_bm²/T_c` 这样的**等号**关系，而不是 P/R 的 max/min。
4. 若要保留"静态决断更快"的诉求，正确做法是**在静态时把 `R` 降到真实白噪 `σ_m²`**
   （因为静态时动态加速度/软铁扰动最小，白噪确实更小），而**不是**去抬 P 或压 τ。

## 6 PC 仿真结果（`tools/ekf_session/sim_yaw_tau.py`，蒙特卡洛 30 次）

物理参数全部取自实测（§1）：`ARW=0.0060 deg/√s`、`σ_m=0.33°`、`b_m=2°`、
`σ_b0=0.0087 dps`、`σ_bg=2e-4 dps/√s`、初始失配 `mis~N(0,3°)`。
真值 = 0.02/0.08/0.25/0.6 Hz 正弦叠加（升余弦包络，前后 4 s 静止），
在 t=12 s 处给地磁**再加 2° 偏置阶跃**。指标：
① 机动段 1 s 增量误差 rms（短期保真度，陀螺物理底 = **0.0090°**）；
② 末段绝对误差 rms；③ 阶跃后 4 s 内误差峰值 / 残余（= 地磁偏置注入）。

**地磁偏置 = GM(T_c=60 s)**

| 方案 | ① 1 s 增量 rms | ② 末段绝对 | ③ 阶跃峰值 / 残余 |
|---|---|---|---|
| 纯陀螺（无地磁） | 0.0090 | 3.09 | 0.033 / 0.029 |
| M1 纯 τ=1.5 s | **0.3118** | 3.19 | **1.798 / 1.695** |
| M1 纯 τ=15.85 s | 0.1605 | 1.87 | 0.660 / 0.589 |
| M1 纯 τ=60 s | 0.0651 | 1.99 | 0.264 / 0.235 |
| M1 纯 τ=300 s | 0.0167 | 2.81 | 0.065 / 0.058 |

### 结论（仿真的直接回答）

1. **τ 调小确实把陀螺的短期优势扔掉**：τ=1.5 s 的 1 s 增量误差 0.312°，
   是陀螺物理底 0.0090° 的 **35 倍**；τ=300 s 时降到 0.0167（1.9 倍）。地磁偏置阶跃
   2° 会在 4 s 内被注入 **1.70°（85%）**。
2. **M3（把 `b_m` 建成状态）能达到陀螺自身的增量精度 0.0090°（等于物理底），
   同时把 2° 偏置阶跃完全吃掉（残余 0.029° = 噪声底）**，并且末段绝对误差最好（1.70°）。
   这是唯一"两个目标同时到顶"的结构 ⇒ **不需要 τ**。
3. **固件现状（M4 型：两状态、自然增益）落在最差一档**（0.199°、注入 1.20°），
   与 §8.17.3 实测静止 `K=0.26`（τ≈20 ms）吻合。
4. **诚实的限制**：地磁偏置为**常值**时，`ψ` 的常值误差与 `b_m` 只以**和**的形式被观测
   ⇒ 阶跃仍会漏一部分进姿态（M3 0.42° vs M1 τ=1.5 的 1.87°）。绝对精度最终由
   **初始失配 + 地磁偏置之和**决定，纯 IMU/磁无法再分离，需要外部绝对基准。
   M3 的 `b_m` 收敛依赖**运动**提供的可观测性（静止不动时只能靠先验分配）。

### 仿真自身踩过的坑（记录，避免再犯）

- 真值用 `np.gradient`（中心差分）而估计器用前向积分 ⇒ 快运动下产生 ~0.08° 的**假增量底噪**，
  会把所有方案的差异掩盖；现改为"先给角速度、真值用同一离散积分生成"。
- 3 状态 KF 的协方差传播曾只写了 `P00/P01/P11`，漏掉 `P02/P12` ⇒ 新息分配错误
  （常值偏置场景下 `b_m` 看起来失效）。现用完整 `F P Fᵀ + Q` 标量展开。
