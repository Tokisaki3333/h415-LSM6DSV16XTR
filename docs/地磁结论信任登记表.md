## 0. 铁律（三条）

1. **唯一验明的读取脚本 = `magmap.py`**（工作区根 + `h415-imu42605-/docs/tools/` + `备份_20261013_S2_源码/tools/`，三处同版）。

   - **E6 固定零点**（不做逐录制/逐会话标定就硬编码）

## 2. 三代读取口径（理解时间线的前提）

| 代 | 固件做法 | 数据特征 | 正确用法 |
|---|---|---|---|
| **高频翻转** | 每拍翻转（1040 Hz） | SET:RST ≈ 1:1，两相各数万样本 | 分相各自拟合（`rst_usable=True`） |
| **1024:1** | 每 1024 个 SET 做一次 RST | SET:RST ≈ 1024:1，RST 仅 15~91 个 | **只能 SET-only**（`rst_usable=False`） |

**实测证据（本表作者复现）**：
```
六面整圈84B（高频翻转）  : n_SET 51986 / n_RST 51993  (50.003%)  rst_usable=True
14 份 1024:1 录制        : n_RST  15~91 (0.091~0.100%)         rst_usable=False
```
**⟹ 高频/低频的差别不在物理，而在 RST 的样本数。** 高频时代两相都能拟合；
低频时代 RST 无法拟合，故 `magmap` 判其不可用。

## 3. 结论级登记（逐条）

### 3-A ✅ 已验证：两相是两个不同心的球

| 项 | 结论 | 复现方式与结果 |
|---|---|---|
| 数据 | `证据链归档_20261013/02_加计交叉验证_六面整圈84B.bin`（= `rec_20261012_031605`） | 84 B RAW，全姿态 |
| SET | center `[129732.75 131572.02 131238.61]`，R=8316.6，残差 **0.678%**，n=51986 | `magmap.Frames→calibrate→MagSolver` |
| RST | center `[133038.92 130480.38 132106.24]`，R=8320.5，残差 **0.700%**，n=51993 | 同上 |
| 两相球心距 | **\|Δ\| = 3588 counts = 场强的 43.15%**；半径比 0.99953 | 同上 |
| 判定 | **两相不可混用**；分开后传感器干净到 0.7%，真实各向异性仅 ~1.2% | — |
| 与 `地磁解析根因_定位.md` §E2 比对 | **逐位一致（小数点后 1 位全部相同）** | ⟹ 该文档可信 |

### 3-B ❌ 已否证：`mag_calibration_log.md`（10-12）§9.4 "RESET 零点相对 SET 有约 2.04° 常数偏移"

**用 `magmap` 实测同一份六面数据**：两相球心距 3588 counts，
折算方向偏移 `atan2(3588, 8316) = 23.3°`，**不是 2.04°（差 11 倍）**。
**⟹ 该条不可引用**（疑似来自中点口径或被"每拍翻转"时代的某种混算）。

### 3-C ⚠️ 未验证但**获得独立佐证**：γ σ = 0.820°（9 个 45° 停泊点）

**本表作者独立复算**（免姿态量 `γ = angle(a_g, m)`，14 份录制 + 六面）：
```
γ σ 中位 0.737°（范围 0.382~1.722）   vs 文档 0.820°   ⟹ 一致
```
**⟹ 可引用，但引用时须注明"由本表作者独立复现"而非"文档如此"**。

### 3-D ❌ 已更正：文档译读错误（本表作者自己犯的）

`mag_calibration_log.md` §7.1 "绝对残差 −8.5 / −16.4 / −26.8°，由站位/摆位硬磁主导"
**被本表作者误读为"换摆位硬磁可达 27°"——荒谬。**
正确读法：恒定体坐标硬磁 `c` 产生的航向误差是
`δψ ≈ (c_⊥/|B_h|)·sin(ψ−φ)`，是**随航向的正弦**；8.5/16.4/26.8 只是同一硬磁在三个航向的取值。
**实测反证**：跨 14 份录制（不同时段/摆放/朝向）的 SET 球心散布仅
**0.75° 中位 / 2.83° max** ⟹ 硬磁跨会话只变 1~3°，绝无 27°。
**⟹ 禁止再用"站位硬磁可达数十度"作为在线标定必要性的论据。**

### 3-E ⚠️ 未验证：`mag_calibration_log.md` §9.4 "高频 RESET 对数据质量有恶劣影响"

其判据为 `σz`（SET 17.2 / RESET 24.5~25.5 counts，1.45 倍）。
**但 magmap 实测六面（高频翻转）的 RST 球拟合残差 0.700%，与 SET 的 0.678% 同档 ⟹
RST 本身是干净的**。该说法至少被夸大，其"恶劣影响"更可能来自**混用两相**而非 RESET 通道。

### 3-F ⚠️ 未验证：`mag360_recording_protocol.md`(09-21) §2 "零空间 6 维 / 1 维"

其自检脚本 `selftest_mag360.py` 在工作区内不存在 ⟹ 无法复现。
**本表作者改用自量指标**（机体系磁场方向的 SVD，`s3/s1`；及各轴跨度）：

| 工况 | mz 跨度 | s3/s1 | 可辨识性 |
|---|---|---|---|
| `230659` 纯水平慢转 | **328 counts** | **0.029** | 竖直不可辨识 ⟹ z 行与 c_z 不可辨识 |
| 六面整圈（全姿态） | 16178 | **0.862** | 三轴充分激励 ⟹ 全参数可辨识 |

**⟹ 该文档的定性结论方向正确，但数字须以本表为准。**

### 3-G ✅ 已验证：固件现用零点 `MAG_ZERO_*` 的精度

### 3-H ✅ 已验证：融合收益（真实录制 A/B）

14 份 168 B 录制，`/DESKF_USE_MAG_OBS=0` vs 现固件，判据 = 场自洽度


### 3-I ✅ 已验证：在线标定必要性（**弱**，且不在漂移上）

| 判据 | 实测 |
|---|---|
| 同录制前后半 SET 球心差 | 中位 **158.6 counts = 1.11°**；拟合残差（噪声底）122.3 counts ⟹ **比值仅 1.3** |
| 跨录制 SET 球心散布 | 中位 **0.75°**，max 2.83° |

| **⟹ 结论** | 离线常量已把零点做到与地磁噪声同量级 ⟹ **在线标定的边际收益只有 ~1° 量级**；其真正价值是**捕捉阶跃变化**（新增磁体/换装夹/换外壳）与**长时漂移**，不是跟随慢漂 |
