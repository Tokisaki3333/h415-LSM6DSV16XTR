# EKF 误差状态索引审计（VER=131 修复记录）

## 1 发现：固件里并存**两套索引空间**且被混用

```
存储空间  s_x[EKF_NX=17] : p(0-2) v(3-5) q(6-9, **四元数 4 维**) ba(10-12) bg(13-15) bb(16)
误差空间  dx[EKF_N =16]  : p(0-2) v(3-5) dθ(6-8, **旋转矢量 3 维**) ba(9-11)  bg(12-14) bb(15)
                          ↑ 四元数多占一个存储槽 ⇒ ba 起 误差索引 = 存储索引 - 1
```

IX_*（0/3/6/**10**/13/16，EKF_NX=17）是**存储**索引；P0 初始化、Q 行、H、publish
用的都是**误差**索引（9-11 / 12-14 / 15）。逐处核对：

| 位置 | 用的索引 | 应否 |
|---|---|---|
| `s_P[9..11]`（P0 ba）/`s_P[12..14]`（P0 bg）/`s_P[15][15]`（P0 bb） | 误差 | ✓ |
| Q：`row 9-11 = ba, 12-14 = bg, 15 = bb` | 误差 | ✓ |
| `h->ekf.p_p_bb = s_P[15][15]` | 误差 | ✓ |
| `s_H[0][6+j]`（姿态块）、`s_H[0][8]`（偏航） | 两空间同值 (6-8) | ✓ |
| `s_F[IX_V+i][IX_BA+j]` = F[3..5][**10..12**] | **存储** | ✗ 应为 [9..11] |
| `s_F[IX_Q+i][IX_BG+j]` = F[6..8][**13..15**] | **存储** | ✗ 应为 [12..14]（且 F[.][15] 把 bb 串进了姿态） |
| `ekf_inject`：`dx[IX_BA+i]`=dx[10..12]、`dx[IX_BG+i]`=dx[13..15] | **存储** | ✗ 应为 dx[9..11] / dx[12..14] |
| `s_x[IX_BB] += dx[15]` | 存储+误差混用 | ✗ 且与 bg_z 撞车 |

## 2 后果（与实测完全吻合）

- 注入错位：`ba ← (ba_y, ba_z, bg_x)`、`bg ← (bg_y, bg_z, bb)`，
  ⇒ **ba_x / bg_x 永远得不到修正**，bb 收到 bg_z 的修正。
- 实测：`ekf.ba`（col96-98）**恒为 0**、`ekf.bg`（col99-101）**≈0**（−0.002…−0.011 dps）
  ⇒ 陀螺常值零偏（300 s 静止实测 **(+0.0947, +0.2959, +0.0156) dps = (+341, +1065, +56) deg/h**）
  **从未被估计/补偿**，只能靠地磁与重力持续牵引（这正是"运动中积攒的残差"的主因之一）。
- F 里 `F[6..8][13..15]` 还把气压实偏 bb 耦进了姿态（yaw ← bb）。

## 3 修复（VER=131，状态数不变）

引入 **EI_\* 误差状态索引宏**并写明铁律：

```
EI_P 0  EI_V 3  EI_Q 6（旋转矢量 3 维）  EI_BA 9  EI_BG 12  EI_BB 15
铁律：s_P / s_Pn / s_F / s_G / s_H / s_K / s_dx 一律用 EI_*；只有 s_x 用 IX_*。
```

并把 `s_F`、`ekf_inject`、Q 行判断、`s_dx` 读取全部改用 EI_\*（见
`tools/ekf_session/patch_v131_ei_index.py`，逐行 diff 核验只动预期位置）。
