# 加速度计在现有固件里的角色 · 惯导能力评估

一句话结论：**加速度计不是"只用于重力方向"**——捷联递推是有的（`f→dv→v→p`，且输出世界系 `a_nav`）；
但**没有可用的惯导能力，而且是刻意的**：速度带姿态自适应的泄漏阻尼、零偏状态被限幅 ±5 mg，
p/v 靠 ZUPT/GPS 撑着，属"有界惯性/半惯导"，不是自由惯导。

---

## 1. 加速度计现在承担的四件事

| # | 用途 | 代码位置 / 常数 |
|---|---|---|
| 1 | **重力方向 → 倾斜观测**（姿态自稳定主轴） | `ekf` 内重力/倾斜观测，σ=`V5F_EKF_SIG_A_MPS2`(2.21 mg)；门控 `gate->ekf_tilt`、`h->ekf.grav_ok`、`grav_nis`、`sigma_tilt_deg`、`tilt_dq*`、`tilt_inv_ms` |
| 2 | **比力推进（捷联）** | `f[i] = (accel_lsb[i]-b0[i])/lsb_per_g*g`；`f[i] -= ba[i]`(行 479)；`s_dvb[i] += f[i]*dt`(行 1384)；`dv = R(q)·Δv + [0,0,-g·dt]`；`p += v·dt + ½a·dt²`(行 987) |
| 3 | **世界系比力输出** | `a_nav = dv/dt`（行 985/990）→ 就是"合加速度"，对地磁/重力系 |
| 4 | **零偏 ba 估计 + 门控/标定** | 状态 `IX_BA`，限幅 `V5F_EKF_BA_LIM_MPS2 = 0.05`（±5 mg），随机游走 `SIG_BA_RW=0.01`；`proc_accel_cal`（静态 b0）；`proc_acc_gate`（\|a\| 偏离 1 g ⇒ 牵引）；`mag.trust` 与 `ekf_zupt` 的 \|a\|≈1 g 判据；向心补偿 `TILT_AC_ARM_M=0.15 m`/`TILT_AC_ERR_DEG=1°` |

即：姿态靠 (1)，运动靠 (2)，对外输出 (3)，健康/约束靠 (4)。

## 2. 为什么说"没有有效惯导能力"

| 项 | 现状 | 影响 |
|---|---|---|
| 速度阻尼 | `dv -= v·λ·dt`，`λ = V5F_EKF_VLEAK_K(5.0)·σ_tilt` | σ_tilt=1° → τ≈11.5 s；姿态越好泄漏越弱。**主动把速度往零拉**，避免姿态误差造成无界漂移 ⇒ 有界而非自由 |
| 速度死区 | `VDEAD_K = 0.0`（未启用） | 若开启可按 σ_tilt 阈值清零水平 dv |
| 零偏限幅 | `BA_LIM = ±5 mg` | 结构上写死。残差 5 mg = 0.049 m/s² → 10 s 漂 ~2.5 m、60 s ~88 m；超出部分无法吸收 |
| ba 可观测性 | 主要靠速度参考（ZUPT/GPS 速度）与重力一致性 | 无速度参考时基本不可观，只能靠"固化标定" |
| ZUPT 条件 | `e_ac<0.20 dps²`、\|a\|=1 g±3%、\|a_lin\|²<0.0025、速度<0.5 m/s、软权 `vel_soft/255`（σ=0.05 m/s） | 只在真静止时可用 |
| 分辨率/噪声 | ±16 g/16 bit = **0.488 mg/LSB** = 4.8e-3 m/s² | **不是瓶颈** |
| 姿态误差耦合 | 1° 倾斜误差 = 17 mg 假水平比力 | 10 s 位置误差 ~4.9 m；0.1° → ~0.49 m ⇒ **姿态精度就是惯导精度上限** |
| 时间同步 | dt 来自 `drdy_tick`（10 ns 计数） | Δt 误差 1 ms × 1 g = 0.0098 m/s 速度误差 |

结论：**p/v 的可信区间是"秒级、低动态、且有 ZUPT/GPS 支撑"**；一旦断开参考源，它就是缓慢发散的量。
对外应把它当"运动信息"，不要当导航源（与 GPS 那篇的结论一致：导航交给飞控自己的滤波器）。

## 3. 要变成"可用惯导"需要按顺序补的东西

1. **零偏可观测性**：静态多位置标定 + 温度项（固化进固件，`proc_accel_cal` 已有静态 b0 的骨架）；
   视需要放开 `BA_LIM`（现在 ±5 mg 是为姿态服务的紧约束）。
2. **自由惯导分区**：有速度参考/机动时 `λ→0`，无参考时才泄漏；同时**输出 σ_p/σ_v**，让飞控自己判断能不能用。
3. **姿态精度**：把倾斜误差压到 0.1° 级（标定 + 温度 + 杆臂），否则惯导上限就被它锁死。
4. **时间/几何**：GPS 与 IMU 的延时对齐、杆臂补偿、削顶帧处理。
5. **观测纪律**：GPS 只进 p/v，禁止通过 P_qv 反污 q/ba/bg（见 `gps_fusion_architecture.md`）。

## 4. 结论（对外一句话）

本模块的对外契约应是：**姿态（重力系四元数，自稳定）+ 合加速度（世界系）+ σ/门位/健康位**；
p/v 只作**辅助运动信息**输出（带不确定度），惯导/导航由飞控或独立 nav 滤波器负责。
