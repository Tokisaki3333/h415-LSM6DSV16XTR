> 加入时间：**2026-10-13**（配套离线仿真 `igg_sim.py`，设计文档 `ekf_native_gate_design.md`）
> 本记录由 **2026-10-14** 会话整理归档；该会话 **撤销了它在地磁通道上的应用**（见 §6）。
> 代码位置：`V5F/User/src/proc_eskf.c`（常量 :140-153；实现 :384-410；调用 :1180 磁 / :1225 重力）

## 1. 它要解决的问题

**加计被运动污染时，重力观测会把错误倾斜灌进姿态。**

被否证的旧方案（三条，全部淘汰）：

| 旧方案 | 失效原因 |
|---|---|
| **模长门** `\| \|a\|−1 \| < 0.05` | 对**方向型**污染无效。实测 `rec_20261013_232607`（纯平动）的模长偏离仅 **0.0087** ≪ 0.05，门大开，而污染是方向性的 |
| **速率门** `\|ω\| < 20 dps` | 纯平动时 `\|ω\|` 中位仅 **3.37 dps**，门大开 ⟹ 挡不住 |
| **残差门** `resid < acc_thr`（硬阈值） | ★ **必然自锁**：门开条件要求 `resid` 小，而唯一能减小 `resid` 的正是这个门控制的修正 ⟹ 门关 ⟹ `resid` 只能继续开环生长 ⟹ 永久锁死。实测 `rec_20261013_072538`：20 s 剧烈运动后倾斜漂到 **7.78°**，而阈值上限 `ESKF_ACC_MAX_RAD = 0.05 rad = 2.8648°` ⟹ 7.78° > 2.86° ⟹ 永不开启 |

**设计目标**：找一种**与"是否在转动"无关**、且**不会自锁**的污染判据。

---

## 2. 核心判据：`d = rᵀ S⁻¹ r`（马氏距离平方）

```
r = z − h                    新息（z = 加计测得的"上"，h = R(q)ᵀ·v_up 预测的"上"）
S = H P Hᵀ + R               新息协方差
d = rᵀ S⁻¹ r                 马氏距离平方（无量纲，尺度由 S 逐帧自适应给出）
```

**为什么它能挡住纯平动**：`d` 量的是"**这一帧加计离预测重力多远**"，与器件是否在转动无关。
纯平动时 `|ω|≈0`（速率门失效）、`|a|≈1`（模长门失效），但**方向已错** ⟹ `d` 立刻变大 ✓

**为什么用 `d` 而不是绝对度数阈值**：`d` 的尺度由 `S = HPHᵀ+R` 逐帧自适应。
实测五份录制的静止底相差 **1.8 倍**，同一组 `K0/K1` 仍给出正确分布。
反之，若用 `eps < 0.5°` 这类绝对阈值，**必然过拟合**某一份录制。

## 3. 三段权函数与常量

```c
#define ESKF_IGG_K0     1.0f      /* 内点/降权 分界 */
#define ESKF_IGG_K1     3.0f      /* 降权/粗差 分界 */
#define ESKF_IGG_WMIN   1.0e-3f   /* 权下限（★ 不是 0） */
```

```
rd < K0            ⟹ w = 1                                  （内点，全权）
K0 ≤ rd < K1       ⟹ w = (K0/rd) · ((K1−rd)/(K1−K0))²        （降权，IGG-III 标准形式）
rd ≥ K1            ⟹ w = WMIN = 1e-3                         （粗差，压到地板）
最后兜底: if (w < WMIN) w = WMIN                             （永不为 0）
```

**常量来源**：`k0=1.0 / k1=3.0` 取自 **GNSS/INS 鲁棒滤波的常用约定值**，不是本项目拟合出来的。
其适用前提是 **`rd` 为标准化标量残差（内点帧 `rd ≈ 1`）** —— 这一点在 §4 被发现不满足，做了修正。

**权重的作用方式**：`K ← w·K`（实现上是缩放 `PHt`，因此**估计与协方差同步受限，一致性不破**）。

**为什么不硬拒**（`WMIN = 1e-3` 而非 0）：
```
★ 这是为了【避免旧残差门那种自锁】—— w 永不归零 ⟹ 观测始终以 ≥1/1000 权重被施加
★ 且 P 在运动期持续增长 ⟹ 新息标准化后 rd 变小 ⟹ w 一回升 K 立即恢复
```
（**但 §6 显示：`WMIN` 只是把"锁"变成"收敛时间常数 ×1000"，在录制时长内等价于锁。**）

## 4. χ² 自由度归一修正（2026-10-13，同一会话内发现并修正）

**问题**：`d = rᵀ S⁻¹ r` 是 **2 自由度** χ²（重力观测只约束 2 个方向 ⟹ 沿 `h` 的分量已被投影消掉）。
```
E[d] = 2,  E[√d] = √2 = 1.414
而 IGG-III 的 K0=1.0/K1=3.0 是针对【标准化标量残差 r̄~N(0,1)】的约定值（内点帧 r̄≈1）
⟹ 直接用 √d 会把【典型内点帧】判进降权段:
     w = (1/1.414)·((3−1.414)/2)² = 0.445    ← 正是离线算出的静止段 w 中位
```

**修正**：除自由度
```c
float rd = sqrtf((nis > 0.0f ? nis : 0.0f) * 0.5f);   /* = √d / √2 */
```
**修正后**：内点帧恢复到 `rd ≈ 1.0` ⟹ `w = 1` ✓

**实测佐证**：固件静止段 `w` 中位 **0.18~0.20** ⟸ `√d = 1.80` ⟸ `resid 0.236° / σa 0.1312°`。

## 5. 离线验证（`igg_sim.py`，五份录制）

| 工况 | 静止段/运动段 | `w` 中位 |
|---|---|---|
| 静止 | — | **0.44 ~ 0.81** |
| 慢转 | — | **0.001** |
| 纯平动（`232607`） | — | **0.001** |
| 翻滚 | — | **0.001** |
| 翻滚后落台座 | — | 回升到 **0.13 ~ 0.17** |

**关键结论**：翻滚后落台座段 `w` 能**回升**，末段 `resid` 收敛到 **0.153°** ⟹ 当时认为**不自锁** ✓

**当时的判断**（与后来事实的差异见 §6）：
```
"w 下限 1e-3，永不归零 ⟹ 不会像旧残差门那样自锁; P 在运动期持续增长, w 一回升 K 立即恢复。"
"翻滚后落台座段 w 回升 0.13~0.17, 末段 resid 仍收敛到 0.153°"
```

## 6. ★★ 2026-10-14 的再发现：它对【地磁】通道是有害的

### 6.1 结构性问题：`eskf_update` 是两个通道共用的

```
磁:   eskf_update(s_eskf.v_mag, z, rp², rq²)      rp = 0.44°, rq = 4.00°
重力: eskf_update(s_eskf.v_up,  z, rs², rs²)      rs = 0.1312°
                    ↑ 同一个函数 ⟹ 共用同一套 IGG ⟹ 地磁【自动继承】了这套权
```

### 6.2 为什么对重力无害、对地磁有害

```
自锁（或等价的长时收敛）需要【两个条件同时满足】:
   ① 新息 r 远大于 R（⟹ rd 超 K1）
   ② 该状态是"要么修、要么永远错"的

★ 重力: 门开条件是 | |a|−1 |<0.05 且 |ω|<20 dps
   ⟹ 门一开说明加计在测纯重力 ⟹ 倾斜误差【本来就小】⟹ r 小
   ⟹ 即便 P 偏小使 S 塌到 R，rd 也不会越界 ⟹ 【不自锁】
   （实证：任务① 修复后 grav_open 开率 99.2~100%）

★ 地磁: 大运动后新息达 7~14°，而 R⊥ = 0.44° ⟹ 16σ 量级
   ⟹ rd 必定远超 K1=3.0 ⟹ w 必落 WMIN
   ⟹ 收敛时间常数被拉长 ~1000 倍 ⟹ 在录制时长内【表现为锁】
   ⟹ 实证: 去掉地磁 IGG 后，末段 mag_resid 5.598° → 0.661°（降 8.5 倍）
```

### 6.3 代码自己早就写过这个风险

`proc_eskf.c:1116`（2026-10-14 会话前就存在的注释）：
```
"S=HPHᵀ+R 塌到 R ⟹ d=rᵀS⁻¹r 巨大
 ⟹ IGG 判外点 w=WMIN ⟹ 地磁再也拉不回（自锁，与当年重力门锁死同构）"
```
**当时的处置只是加"膨胀 P"的缓解补丁（`ESKF_SIG_NOGRAV`），没有从根上给地磁解耦。**

### 6.4 撤销方式（2026-10-14 已实施）

```c
/* :317 */  static float eskf_update(..., float r_perp, float r_par, uint8_t use_igg)
/* :396 */  if (use_igg == 0u) { w = 1.0f; }        ← 地磁恒权
/* :1180 */ eskf_update(s_eskf.v_mag, z, rp*rp, rq*rq, 0u)   ← 磁不用
/* :1225 */ eskf_update(s_eskf.v_up,  z, rs*rs, rs*rs, 1u)   ← 重力仍用
```

**依据（用户指示）**：地磁不需要 IGG-III 级别门控，且当前不考虑外部磁干扰；
物理条件 `mag_valid` / `new_mag` / `mag_ref_ok` 已足够当质量门。

**PC 复刻验收**（四份转动录制，`grav_open` 全程 0 的连续运动段）：
```
末段 mag_resid:  5.598° → 0.661°（A 025232）
中位 mag_resid:  3.659° → 0.603°
其余三份: 0.659 / 1.189 / 0.162°（末段）
```

## 7. ★★ 未解疑惑（★ 接力者须正面回答）

### 7.1 那个"降 8.5 倍"是真改善还是自证式改善？

```
★ 质疑（用户提出，本会话未反驳）:
   残差的定义就是【姿态与磁的差】⟹ 让滤波器更信磁，残差【必然变小】
   ⟹ 这是【自证式改善】，不能作为"IGG 有害"的证据
   ⟹ 若磁本身有误差，姿态会被拽到磁的方向 ⟹ 残差小但姿态错
★ 需要: 一个【独立于磁】的判据来评价该撤销
   （候选：与重力倾斜的一致性、航向复现性、外部真值对比、P 的诚实性检验）
```

### 7.2 `WMIN = 1e-3` 的"地板"是否真的防锁？

```
★ 它防的是【数学意义】的锁（w 归零 ⟹ 永不再修）
★ 但 w=1e-3 ⟹ K 被压 1000 倍 ⟹ 收敛时间常数 ×1000
  ⟹ 对 20 s 量级的录制，等效于锁
★ 所以"w 下限 1e-3 不会自锁"这个论断【在时间尺度上是可疑的】
```

### 7.3 重力的 IGG 该不该保留？

```
★ 保留理由: 加计确实会被运动污染（纯平动的 232607 实测 w=0.001 是正确的行为）
★ 但 §3 的两个物理门（模长门 + 速率门）是否已足够？未验证
★ 若去掉，重力通道就与地磁通道同构（都靠 K=P/(P+R)）
   ⟹ 好处: 结构简单、无隐藏权
   ⟹ 风险: 运动中加计污染会直接进姿态（但速率门 |ω|<20 dps 已挡住翻滚段）
★ 建议: 用一份"纯平动 + 重力门开"的录制做 A/B 验证后再决定
```

### 7.4 χ² 自由度归一（`√(d/2)`）对地磁是否也适用？

```
★ 地磁观测同样只约束 2 个方向（沿场方向不可观）⟹ 自由度也是 2
★ 但地磁现在不走 IGG ⟹ 该归一当前对地磁无影响
★ 若将来给地磁加任何基于 d 的判据，必须同样除自由度
```

## 9. 一句话总结

```
IGG-III 三段权是 2026-10-13 为【挡住加计的方向型污染】而设计的，
它正确地解决了"纯平动挡不住"的问题，并用 χ² 自由度归一修正了常量适配问题。

但因为它被放在【两个通道共用的 eskf_update】里，地磁也自动继承了它，
而地磁的大新息（7~14° vs R=0.44°）必然落进 WMIN，
⟹ 使地磁的收敛时间常数被拉长 1000 倍 ⟹ 表现为"牵引弱/锁"。

2026-10-14 已用 use_igg 参数把两者解耦（磁不用、重力仍用）。
★ 该撤销的评价判据（独立于磁）尚未建立 —— 见 §7.1，这是最重要的未决问题。
```
