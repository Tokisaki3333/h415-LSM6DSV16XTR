# 标定夹具（Calibration Fixture）

> **本夹具就是实际标定所用的那套，实测勉强能用、精度不错。**
> 但其核心机制「预应力抗背隙」在原理上没有效果（详见下文），
> 且对轴承型号有特定依赖、转动时非轴向形变严重。
> **⟹ 结论：可用，但建议仅作参考，不建议照抄设计。**

## 用途

用于传感器（地磁 / 陀螺）标定的**转台夹具**：由上下齿轮 + 支架 + 齿轮台组成，
用以在标定过程中提供已知角度的旋转。

**本夹具已实际用于本工程的标定工作，结果勉强可用、精度不错**
（六面整圈标定的 SET 相球拟合残差达到 0.678%，见
[`docs/地磁结论信任登记表.md`](../../docs/地磁结论信任登记表.md) §3-A）。

## 装配所需五金（BOM）

| 项 | 规格 | 数量 | 备注 |
|---|---|---|---|
| **轴承** | **内径 = 25 mm、外径 = 37 mm、厚度 ≤ 7 mm** | 1 | 型号受此尺寸约束，**非通用件**（这就是"需要特定型号轴承"的具体含义） |
| **M3 铜柱** | 长度 **≥ 7 mm**，**建议 15 mm 以上** | **3** | 铜柱（brass），非磁性 |
| **M3 螺丝** 或 另加 3 根铜柱 | 无特殊要求 | **3** | 用于固定上/下部件 |
| **M3 黄铜螺丝** | 无特殊要求 | **2 ~ 4** | **用于固定 PCB**；务必用**黄铜**（非磁性） |
| ⚠️ **M3 304 不锈钢螺丝** | — | — | **304 不锈钢有弱磁性**。若使用，**靠近地磁传感器的螺丝位置必须留空**，否则会污染磁标定 |

**关键提示**：本夹具用于**地磁标定**，因此**靠近传感器一侧的紧固件一律用黄铜/铜，或干脆留空**。
304 不锈钢（乃至普通碳钢）螺丝会带硬磁/软磁干扰，直接破坏标定结果。

## 装配的两种方案

### 方案 A：用轴承（原始设计）

按上文 BOM 采购轴承装入「支架」，转动轴由轴承支撑。
精度优先，但对轴承型号有依赖（内径 25 / 外径 37 / 厚度 ≤ 7 mm，非通用件）。

### 方案 B：不用轴承（推荐尝试）

**也可以直接修改「支架」模型中转动轴的直径**，把它**改小**，
使其**避开轴承、直接支撑「上齿轮」与「下齿轮」**。

- 好处：**省掉那个非通用型号的轴承**，装配更简单、成本更低；
- 代价：转动摩擦与径向跳动会比轴承方案大，
  是否满足标定精度需自行实测（本工程未在此方案下验证）。

> ⚠️ **无论用哪种方案**：修改「支架」时，
> **建议在切片软件中对"转动轴与支架的连接处"做加强**（加厚/加密填充/加圆角过渡）。
> 该处是悬臂受力的根部，也是最容易断或变形的地方。

## 实测结论（如实记录）

原始设计意图是用**预应力（预紧）的方式消除齿轮背隙**，以保证标定转台的角度精度。

**实际使用结论：本夹具确实勉强能用、精度不错**（已用于本工程的六面整圈标定）。
但**上述"预应力抗背隙"机制本身并没有起到设计所设想的作用**，原因如下：

1. **「预应力抗背隙」设计根本没有效果** ——
   **3 mm 模数的齿轮用 3D 打印做出来本身就已经没有背隙了**，
   不需要、也无法通过预紧进一步改善；预紧反而引入额外问题。
2. **该设计需要特定型号的轴承**，不是通用件，可替换性差
   （具体规格见上文 BOM：内径 25 / 外径 37 / 厚度 ≤ 7 mm）。
   → 可考虑改成**方案 B**：改小「支架」转动轴直径、**直接支撑齿轮而不用轴承**
   （见上文"装配的两种方案"）。
3. **转动时非轴向形变严重** —— 旋转过程中产生明显的非轴向变形。

**⟹ 综合结论：**
- **作为标定夹具：可用**（实测精度够用，本工程标定即用它完成）；
- **作为设计参考：仅作参考，不建议照抄** —— 预应力抗背隙这一思路无效，
  且轴承选型受限、转动形变明显。

## 若要继续这条路线，建议方向

- 放弃预应力抗背隙思路，改用**成品精密齿轮**或**直驱（DD）电机**方案；
- 或改用**光学/磁性角度基准**（如增量编码器）替代机械齿轮传动，
  从根上避开背隙与形变问题；
- 若必须 3D 打印，需重新核算轴承座刚度与齿轮模数，并实测转动下的非轴向形变。
