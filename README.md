> **本 README 记录真实进度，包括未完成与已知缺陷。** 详细结论级证据见
> [`docs/地磁结论信任登记表.md`](docs/地磁结论信任登记表.md)（结论引用闸门）与
> [`docs/接力_20261014_地磁与ESKF.md`](docs/接力_20261014_地磁与ESKF.md)（交接）。

## 简介

MRS2 工程（沁恒官方推荐 IDE）。基于 **沁恒 CH32H417**（双核 RISC-V）的
多传感器融合姿态平台。

**当前状态一句话**：传感器采集与时间戳链路已完整可用；ESKF 姿态融合已跑通
（重力通道已验证正确，地磁通道于 2026-10-14 首次达到"能正确牵引"的状态），
**但地磁参考方向仍有约 1.4° 标定误差未解决**，详见下文"已知缺陷"。

## 目录结构

```
h415-imu42605-/
├── V3F/        # 小核固件 User 工程（传感器采集侧）
├── V5F/        # 大核固件 User 工程（姿态/输出侧，含多传感器汇总）
├── Common/     # 两核共享公共源码（外设驱动、LVGL、GPS、Debug 等）
├── docs/       # 设计文档、证据记录、结论信任登记表、分析工具
└── CH32串口陀螺仪.wvsln
```

V3F/、V5F/：两核私有工程，含各自链接脚本、main.c和内核强相关库

下面文件夹被俩工程以外部链接形式共同引用：

- `Common/Peripheral`、`Common/Core`、`Common/Startup`、`Common/USBHS`：WCH 标准外设库/Core，
  基本来自芯片 EVT 模板，除非修改否则无需关注。
- `Common/Common`：工程自有外设驱动与功能模块。

**核心软件逻辑：** 小核完成全部传感器初级采集和时间戳记录（以DRDY就绪为准）随后通过多种方式共享给大核：

1. 对于陀螺仪有唯一特殊接收方式：小核在陀螺仪DRDY中断内首先记录中断事件存入共享ram，然后激活spi-tx接收一段新帧；
   大核常时使能SPI-rx-DMA中断，大核在DMA中断内读当前帧并进行主算法，该中断以8Khz发生，125us的总时间目前只用了5us相当充足；
2. 对于地磁、气压、GPS等低速传感器，小核存入共享ram，并以cnt自增来表示新数据，大核在8Khz中断中轮询、同步；

这样就实现了 大核拿到带有精确时间戳的全部数据 （目前有且仅有GPS时间戳有ms级别误差需要重构解码器）

**辅助软件逻辑：**

- 带一个字库为了避免每次烧录耗时故关掉全擦选项、提前烧录并在后续代码假定其存在
- 还有个4*3字库随代码每次下载（感谢Michaelangel007大佬的字库）
- 显存在共享ram，小核主循环抽空刷新到oled，故显示函数双核对称
- 事实上整个4G寻址空间基本对双核对称，故大核有很多外设没有初始化就直接用了，甚至双核可以同时用printf抢占同一个外设
- 小核主循环期望两个等待DRDY的函数均延时超过1us以免错过DRDY变化沿
- 气压计疑似买到假的了DRDY无效，改用了轮询寄存器
- CDC串口在主循环可选开启，附带通过按键回到烧录模式的选项（以避免全擦编程，理由同上保护字库）

### 刚修复、待继续观察

**地磁通道**（2026-10-14，`ESKF_BUILD_VER = "ESKF-20261014-0715-nograv-3deg20s"`）

修复三处缺陷后，磁牵引首次达到"牵引目标无误位"：

1. **`v_mag`（导航系磁场参考）此前从未被构造**，停在初值 `[0,1,0]`（水平假参考），
   导致磁观测把姿态拉歪 54°。现改为**静止窗实测等效公式**：
   `zb=a_mean/|a_mean|`、`um=u_mean/|u_mean|`、`yb=normalize(um−(um·zb)zb)`、
   `xb=zb×yb`、`v_mag = R0·um` —— **不假设上电后地磁在机体系的角度**，
   而是用上电后实测的重力方向与地磁矢量方向在世界系中定出姿态，再求地磁的世界系方向。
2. **磁观测改为纯净路径**：无门控、无 IGG 降权、无单帧限幅、无"地磁不可用"兜底
   （单帧限幅改只作用于重力通道）。
3. **PC 复刻注入帧须跳过 USB CDC 陈旧段**（原实现注入了陈旧帧姿态，
   使前 4.4 s 出现 `acc_resid` 89° 的假象）。

**验收**（`rec_20261014_080336`，45 s）：
`acc_resid` 中位 **3.8718°**、前 100 帧 **0.9940°**；
`mag_resid` 中位 **0.345°**、p95 **1.243°**。

### 已知缺陷（未完成）

1. **地磁参考方向有约 1.42° 标定误差** ← **当前最大的已知问题**
   - 链内 `v_mag` 倾角 **58.7935°**，物理真值约 **57.37°**。
   - 该偏差被磁观测如实拉入姿态，表现为"小 `mag_resid` + 约 1.4° 姿态偏差"，
     **自洽因而无法自纠**。
   - 已排除：零点（固件零点 vs 分相球心仅差 78 counts）、轴序（48 组排列×符号穷举）、
     RST 帧处理（严格分相，不足 100 样本即弃用）、加计竖直（静止期散布 < 0.01°）。
   - 待查方向：传感器于 2026-10-14 02:24 由**触发模式（743 Hz 上报）**改为
     **连续模式（1205 Hz 上报）**，该改动会改变地磁表观值 ⟹ 零点需在新模式下重标。
2. **`v_mag` 构造窗（上电后约 0.83 s）内 `mag_resid` 上报约 60° 假值**
   （该窗内观测尚未施加，仅为诊断读数，**不影响姿态**）。
3. **GPS 时间戳 ms 级误差**，解码器待重构。
4. **气压计 DRDY 无效**（疑假货），依赖轮询。
5. 部分录制在 02:38 之后的 z 轴零点与之前不同，原因未查清。

## 结论引用闸门（重要）

本项目地磁分析长期被**读取口径错误**污染，文档跨越三代口径。因此建立
[`docs/地磁结论信任登记表.md`](docs/地磁结论信任登记表.md) 作为引用闸门：

- **唯一验明的读取脚本 = `docs/tools/magmap.py`**（三处同版，md5 `94A1050B80BD70A1`）
- **时间戳早于该脚本的地磁说法，一律视为未验证**，要用必须先复现
- 禁止三种口径：E4 中点零点、E5 两相混用、E6 固定零点
- 引用任何地磁结论前必须先查该表；查不到即视为"该结论不存在"

固件    ESKF-20261014-0715-nograv-3deg20s
验收    acc_resid 中位 3.8718°  /  mag_resid 中位 0.345°
        链内 v_mag 倾角 58.7935°，与离线独立复算 58.790° 一致到 0.004°

## 未来计划（承诺）

**本工程尚未完善，我会继续把它做完整，并把每一步的真实结果（包括失败与回退）
写进本 README 与 `docs/`，不粉饰。** 按优先级：

1. **地磁参考重标**：在「连续模式（1.2 kHz 上报）」下重新标定 `MAG_ZERO_*` 与
   `MAG_REF_N`，把地磁倾角误差从 1.42° 压到 **±0.5° 以内**（理论磁精度量级）。
   判据：链内 `v_mag` 倾角与离线独立复算一致，且姿态偏差落入 ±0.5°。
2. **消除剩余诊断假值**：`v_mag` 构造窗内 `mag_resid` 置 0，避免上报误导。
3. **补全验收**：把多重录制的 A/B（磁开 vs 磁关）做成脚本化回归，
   覆盖静止 / 慢转 / 大幅运动三类工况。
4. **GPS 时间戳解码器重构**，消除 ms 级误差。
5. **查找气压计替代方案**（现器件 DRDY 无效）。
6. **在线地磁标定**（目前用离线预标定常量，无法捕捉阶跃变化与长时漂移）。
7. **清理并归档**：分析中间产物统一输出到 RAM 盘，仓库保持只含源码与文档。

**明确未做**：在线地磁标定、GPS 融合、气压高度融合、
以及动态性能的完整量化验收（现有验收仅覆盖有限录制）。
